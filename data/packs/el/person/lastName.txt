description: Greek surnames in the masculine form, roughly frequency-ordered. Greek full names carry a single surname, so draw once. Greek surnames inflect by gender — a woman carries the genitive form of the same surname: -ος -> -ου (Παπαδόπουλος -> Παπαδοπούλου, with the accent moving to the penult), -ης -> -η (Παπαδάκης -> Παπαδάκη), -ίδης -> -ίδου (Πετρίδης -> Πετρίδου), -άδης -> -άδου, -ας -> -α (Δούκας -> Δούκα). Surnames that are already a genitive (Οικονόμου, Γεωργίου, Χαραλάμπους, -όγλου) are identical for both genders. For the feminine list use person.female.lastName, which is this list line for line. The split is by design, not an oversight.
locale: el
