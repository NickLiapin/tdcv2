description: Informal short name in Faroese. Read this before using it: the list overlaps person/male/firstName and person/female/firstName heavily, and that is BY DESIGN. Faroese given names are already short, and most of what would be a nickname elsewhere is itself a registered Faroese given name that a person is christened with - Óli, Bogi, Súni, Rúni, Sanna, Malan. What is left is the -i familiar formed by clipping a longer name (Hansi, Tummi, Siggi, Kalli). The list is deliberately short rather than padded, because a longer one would have to be invented.
locale: fo
