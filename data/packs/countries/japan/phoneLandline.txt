address: japan.phoneLandline
description: Japanese fixed-line number in national form, 0AB-CDE-FGHJ. The area code is VARIABLE-LENGTH, which is unusual and is the whole point of this file: written with the trunk 0 it runs from two characters to five - 03 (Tokyo), 011 (Sapporo), 0267 (Karuizawa), 01267 (northern Hokkaido) - and the local exchange code shrinks to match, because the rule is that trunk 0 + area code + exchange code is always exactly six digits and the subscriber number always four. Every landline number in Japan is therefore ten digits, but you cannot split one into area and exchange without knowing the area. The area codes here are real; the exchange and subscriber digits are structural. The four five-character codes are the genuinely rare ones - 01267, 04992, 05769, 09496 - and 05979 in Mie is the case where the exchange code itself is a single digit.
generator: tdc
