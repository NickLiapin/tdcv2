---
address: turkey.finance.iban
description: Turkish IBAN — 26 characters: TR + 2 ISO 7064 mod-97-10 check digits + a 5-digit national bank code + one RESERVED digit + a 16-digit account number. The reserved digit is a real field, not padding: the TCMB communiqué holds it for a future extension of the scheme and it is always 0 today, so a validator that treats the 16-digit account as 17 will pass numbers the banks reject. The bank code is drawn from turkey.finance.bankCode, so the bank in the IBAN is a bank that exists. The account behind it is denominated in Turkish lira, and lira amounts are a trap in historic test data: on 1 January 2005 the currency was revalued at 1 000 000 old lira (TRL) to 1 new lira, so a pre-2005 balance is a million times the same sum today. The transitional 2005-2008 name was Yeni Türk Lirası (YTL); the code has been TRY since 2009.
generator: tdc
---
<sequence name="bank"><gen type="template" value="turkey.finance.bankCode"/></sequence>
<sequence name="account"><gen type="regex" value="[0-9]{16}"/></sequence>
<sequence name="iban"><compute>
  <!-- reserved digit, always 0 -->
  <let name="bban"><concat><field name="bank"/><str v="0"/><field name="account"/></concat></let>
  <!-- ISO 13616: move the country code and a "00" placeholder to the end. -->
  <let name="rearranged"><concat><use name="bban"/><str v="TR"/><str v="00"/></concat></let>
  <let name="digits"><join><each>
    <over><use name="rearranged"/></over>
    <do><encode as="base36"><current/></encode></do>
  </each></join></let>
  <!-- Horner fold, so the 26-digit value never has to exist as one number. -->
  <let name="rem"><reduce>
    <over><use name="digits"/></over>
    <init><int v="0"/></init>
    <do><mod><add><multiply><acc/><int v="10"/></multiply><current/></add><int v="97"/></mod></do>
  </reduce></let>
  <let name="check"><pad width="2" fill="0"><subtract><int v="98"/><use name="rem"/></subtract></pad></let>
  <result><concat><str v="TR"/><use name="check"/><use name="bban"/></concat></result>
</compute></sequence>
<data>${{iban}}</data>
