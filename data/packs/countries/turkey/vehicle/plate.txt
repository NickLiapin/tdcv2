address: turkey.vehicle.plate
description: Turkish registration plate — the two-digit province code, then a letter group, then a digit group, written with spaces between all three, e.g. 34 ABC 12. The province code is drawn from turkey.geo.provinceCode, so 06 really is Ankara and 35 really is İzmir; unlike most European plates it is the same number that opens every postal code in that province. The issued combinations are 1 letter + 4 digits, 2 letters + 3 digits, 2 letters + 4 digits and 3 letters + 2 digits. Where this generator departs from reality: the 2-letter-4-digit form was opened only for the largest provinces when their shorter series ran out, but it is emitted here for all 81 codes, so a plate like 75 AB 1234 is well-formed and not issued. The letters are the 26 ASCII letters only — Turkish plates carry no Ç, Ğ, İ, Ö, Ş or Ü, so this is one Turkish string that survives an ASCII upper() intact.
generator: tdc
