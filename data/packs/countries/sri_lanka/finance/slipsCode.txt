description: The Sri Lankan domestic routing key — SEVEN digits, a 4-digit LankaClear bank code (sri_lanka.finance.bankCode) followed by that bank's own 3-digit branch code, written together with no separator: 7056080 is Commercial Bank, Nugegoda. It is what addresses a SLIPS or LankaPay CEFTS transfer, an EPF remittance, a salary run and a cheque through clearing, and it is the field a Sri Lankan payment file needs where a European one would want an IBAN. SRI LANKA HAS NO IBAN. It is not in the IBAN registry, it never joined the scheme, and there is deliberately no sri_lanka.finance.iban in this pack: a domestic transfer is addressed by this seven-digit code plus an account number, an inbound international one by SWIFT/BIC plus an account number, and a config that generates an LK-prefixed IBAN is generating something that does not exist and that no Sri Lankan bank will accept. The check digit lives in the BANK half only. The fourth digit checks the first three under weights 7,3,1 mod 10 — the evidence is set out in sri_lanka.finance.bankCode — and the three branch digits carry NO checksum at all: they are each bank's own serial, allotted in its own order, so nothing in the last three digits verifies anything and a mistyped branch code produces another well-formed routing key. Head office is usually 001 or 002 depending on the bank. This file draws the branch part 001-999 and does not model which branches a given bank has actually opened; the largest networks run to several hundred (the Regional Development Bank alone publishes about 270), the foreign banks to a handful, so a value here is a real bank with a well-formed branch rather than a branch that exists.
