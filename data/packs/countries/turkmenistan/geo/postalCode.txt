description: A Turkmen postal code — six digits, written on its own line below the locality, or below the country name on international mail. This is a DRAWN code and not a list, and the reason is the honest answer rather than a shortcut: Türkmenpoçta publishes no postcode register. GeoNames, which ships a postal-code file for most of the world, has no TM dataset at all (download.geonames.org/export/zip has TC, TH and TR and no TM), and the aggregator sites that claim to have one disagree with each other on the province ranges. What IS published is the format and a handful of real codes. The Universal Postal Union's addressing sheet for Turkmenistan (12/2020) states "6 digits below locality or country name", says the coding follows the administrative divisions — welaýat at level 1, etrap at level 2 — and prints four working examples: 744000 for the main Aşgabat delivery office, 744005 and 744027 for other Aşgabat offices, 745100 for Balkanabat in Balkan province, and 746150 for Hojambaz district in Lebap. Three more come from published street addresses of real institutions: 746100 Türkmenabat, 746300 Daşoguz, 745400 Mary. Every code that could be verified lies in 744000-746999, which is what the pattern below draws from, and the leading 74 is the country's block. What this file therefore does NOT claim: that a drawn code is a code that exists, and that any particular prefix maps to any particular province. The seven verified codes above are the ones to use when the code has to be real. Note also that a Turkmen address puts the postcode BELOW the locality rather than in front of it, which is the opposite of the German and Russian habit and the reason a "postcode city" one-liner is wrong for Turkmenistan.
