---
address: ukraine.finance.iban
description: Ukrainian IBAN — 29 characters, one of the longest in the register: UA + two ISO 7064 MOD 97-10 check digits + the six-digit МФО bank code + a 19-digit account number left-padded with zeros. Ukraine went over to IBAN on 5 August 2019 and the old fourteen-digit account numbers stopped working entirely in 2020, so unlike most of Europe there is no legacy domestic account format still in parallel use. The bank code is drawn from ukraine.finance.mfo, so every value here names a bank that exists. Verified against the published example UA213223130000026007233566001 (МФО 322313, Укрексімбанк): the same arithmetic that generates these accepts it, and rejects it with any single character changed.
generator: tdc
---
<sequence name="mfo"><gen type="template" value="ukraine.finance.mfo"/></sequence>
<sequence name="account"><gen type="regex" value="[0-9]{19}"/></sequence>
<sequence name="iban"><compute>
  <let name="bban"><concat><field name="mfo"/><field name="account"/></concat></let>
  <!-- ISO 13616: move the country code and the placeholder check to the back. -->
  <let name="rearranged"><concat><use name="bban"/><str v="UA"/><str v="00"/></concat></let>
  <let name="digits"><join><each>
    <over><use name="rearranged"/></over>
    <do><encode as="base36"><current/></encode></do>
  </each></join></let>
  <let name="rem"><reduce>
    <over><use name="digits"/></over>
    <init><int v="0"/></init>
    <do><mod><add><multiply><acc/><int v="10"/></multiply><current/></add><int v="97"/></mod></do>
  </reduce></let>
  <let name="check"><pad width="2" fill="0"><subtract><int v="98"/><use name="rem"/></subtract></pad></let>
  <result><concat><str v="UA"/><use name="check"/><use name="bban"/></concat></result>
</compute></sequence>
<data>${{iban}}</data>
