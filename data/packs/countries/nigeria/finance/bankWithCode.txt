address: nigeria.finance.bankWithCode
description: THE SOURCE OF TRUTH for Nigeria's banks. Each line is the 3-digit CBN bank code, one space, then the bank's common name — "058 Guaranty Trust Bank". nigeria.finance.bank and nigeria.finance.bankCode are both sliced out of this list, so a name and its code cannot drift apart, and nigeria.finance.nubanWithBank computes its check digit over the code taken from here. This 3-digit code is the one that matters: it is what a banking app or a *USSD# transfer menu names the destination bank by, it is the first three digits of every one of that bank's 9-digit sort codes, and it is the value the NUBAN check digit is computed over. Do NOT confuse it with the 6-digit NIBSS institution code (First Bank is 011 here and 000011 there) — that longer code exists because the 2018/2020 NUBAN revision widened the field to admit microfinance banks, mobile-money operators and payment service banks, and it is deliberately zero-padded so that 000011 and 011 produce the SAME check digit. Also not a SWIFT/BIC: GTBank is 058 here and GTBINGLA there. Only licensed commercial and non-interest (Islamic) banks are listed; Nigeria has hundreds of microfinance banks and fintech wallets with their own 6-digit codes, and none of them is here. Ordered by code, which is also why the list is not ordered by size. Heritage Bank is absent on purpose: its licence was revoked and it was liquidated in June 2024, so its code no longer routes anything.
