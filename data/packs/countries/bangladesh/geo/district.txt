address: bangladesh.geo.district
description: All 64 DISTRICTS (জেলা, zila) of Bangladesh in Bengali, ordered alphabetically by their official English name so the file is index-aligned line for line with bangladesh.geo.districtEnglish. The district is the SECOND administrative layer, under the 8 divisions in bangladesh.geo.division, and it is the layer that actually organises Bangladeshi life: a district has a Deputy Commissioner, a district judge, a district hospital, its own police, and it is the unit a postal code block, a bank routing code and an NID number are all keyed to. Both layers are real and the pack keeps them apart on purpose — a config that models Bangladesh with one "region" list will produce records that no Bangladeshi form could accept. Below the district sit 495 upazilas (উপজেলা), which this pack does not enumerate. The count has been 64 since 1984, when the old 21 greater districts were broken up; the number has not moved since, so unlike the divisions this list is stable.
