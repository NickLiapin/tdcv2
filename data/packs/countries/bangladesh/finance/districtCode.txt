address: bangladesh.finance.districtCode
description: The 2-digit district code that sits in positions 4-5 of a Bangladesh Bank routing number, index-aligned line for line with bangladesh.geo.district and bangladesh.geo.districtEnglish. Every one of the 64 was read off real published routing numbers, so this is a verified list rather than a reconstruction. The numbering is alphabetical over the OLD English district spellings with gaps left between them, which is why it looks almost sorted and then is not — 38 is Joypurhat and 39 Jamalpur because the district was spelled Jaipurhat when the codes were cut, 70 is Chapai Nawabganj because it was plain Nawabganj and sorted under N, 81 is Rajshahi but 82 is Rajbari, and 86 is Shariatpur while 87 is Satkhira. Every gap in the sequence is a district that was renamed or a slot held open, and none of it is derivable — it has to be looked up, which is why the list is here. One code is deliberately missing: Dhaka has TWO, 26 and 27, because the capital's branches overflowed the 3-digit branch field and the bank opened a second block. Only 26 is listed, so that the file can stay one line per district and index-align with the geography; a real routing number with 27 in it is a Dhaka number and is valid. This is the BANK's district list and it is not the Election Commission's — the codes in an NID are a different system, and bangladesh.docs.nid explains why this pack will not claim to know that one.
