description: Philippine ZIP code — exactly 4 digits, issued by the Philippine Postal Corporation (PHLPost). The name is borrowed from the United States along with much of the postal apparatus, but the number is not: a US ZIP is 5 digits, a Philippine ZIP is 4, and there is no ZIP+4 extension. Codes in use run from 0400 to 9811, so the range here is drawn over that span rather than over all 10,000 combinations; the leading zero is real and must be kept as a string, because 0400 is a Rizal code and 400 is nothing. The first digit is a broad island grouping and the rest identify the delivery post office: 1xxx is Metro Manila (Manila proper 1000-1096, with the rest of the region running up to about 1799), 2xxx-3xxx northern and central Luzon, 4xxx-5xxx southern Luzon and Bicol, 6xxx the Visayas, 7xxx-9xxx Mindanao. NOT EVERY 4-DIGIT NUMBER IN THE RANGE IS AN ISSUED CODE — the assignment is sparse — so a drawn code is structurally right and not guaranteed to be deliverable. In practice Filipinos write the ZIP inconsistently or leave it off entirely and let the barangay and city carry the address, which is why Philippine address data very often has a blank or wrong postal code and why a validator that insists on one will reject real records.
