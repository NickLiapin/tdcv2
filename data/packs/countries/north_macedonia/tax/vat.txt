description: The Macedonian VAT identification number (даночен број за ДДВ) — the country code in front of the 13-digit ЕДБ, and nothing else. There is no separate VAT register number here the way Poland issues a NIP that becomes PL+NIP or Serbia issues a PIB: a Macedonian taxpayer registered for ДДВ quotes the ЕДБ it already had, with the prefix, and the same number identifies it for corporate tax, for customs and in the Централен регистар. So the check digit, the structure and the caveats are all north_macedonia.tax.edb's — read that file before this one, especially its note on the one published number whose control digit does not satisfy the strict rule. TWO THINGS ARE PARTICULAR TO THE VAT FORM. First, North Macedonia is NOT in the EU, so this number is not in VIES and cannot be validated against the Commission's service; a European supplier treating it as an EU VAT ID gets a lookup failure and, in most invoicing software, silently drops the reverse charge. The country has been a candidate since 2005 and negotiations opened in 2022, so this may change and has not. Second, and this is a real trap: the prefix is printed as МК in Cyrillic on domestic invoices — ФЕИТ publishes its number as МК4057009100101 — while international documents use the Latin MK, and in most fonts the two are visually identical while being different code points (U+041C U+041A against U+004D U+004B). A string comparison, a regex on ^MK, a database unique index and a deduplication pass all see two different numbers. This file emits the LATIN form, because that is what a cross-border document carries and what every other country pack in this project writes, and a config that needs the domestic form should substitute the Cyrillic prefix knowingly rather than by accident. The standard ДДВ rate is 18%, with reduced rates of 10% and 5%, and the registration threshold is turnover of 2,000,000 денари — a little over 32,000 euro at the peg — so a great many small Macedonian traders hold an ЕДБ and no VAT number at all.
