address: iceland.geo.postalPlace
description: Icelandic postal place names in the DATIVE CASE, deduplicated from Iceland Post's postal code register — these are the forms that stand after the code on an envelope (Hafnarfirði, Kópavogi, Akranesi, Selfossi, Vestmannaeyjum), not the forms a sentence would use to name the town (Hafnarfjörður, Kópavogur, Akranes, Selfoss, Vestmannaeyjar). Iceland is the case where the difference cannot be papered over with a lookup table built from the nominative: the ending depends on the noun's declension class and on whether the name is a plural (Vestmannaeyjum, Egilsstöðum, Flúðum, Laugum are all datives of plurals), so it is neither derivable by rule nor safe to guess. Use iceland.geo.city for the name of a town and this for the place it is delivered to; use iceland.geo.postalLine to get the code and the place together and correct.
locale: is
