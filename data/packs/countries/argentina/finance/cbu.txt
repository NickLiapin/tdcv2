address: argentina.finance.cbu
description: Argentine CBU (Clave Bancaria Uniforme) — 22 digits in two independently checksummed blocks. Block 1 is 3-digit BCRA entity code + 4-digit sucursal + mod-10 check digit weighted 7,1,3,9,7,1,3; block 2 is a 13-digit account number + mod-10 check digit weighted 3,9,7,1,3,9,7,1,3,9,7,1,3. A CVU (virtual account at a payment provider) uses the same 22-digit layout and the same two check digits. The alias CBU — a 6-20 character label bound to the account — is NOT part of the number and carries no check digit.
generator: tdc
