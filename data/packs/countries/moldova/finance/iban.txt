---
address: moldova.finance.iban
description: Moldovan IBAN — 24 characters: MD + two ISO 7064 MOD 97-10 check digits + a two-character bank identifier assigned by the National Bank of Moldova + an 18-character account. Short, by European standards; Ukraine next door runs to 29. THE TRAP THIS FILE EXISTS TO CATCH: the account behind an MD IBAN is denominated in the MOLDOVAN LEU, code MDL, which is not the Romanian leu. The two currencies share a name and nothing else — separate central banks, separate issues, separate rates, and about four Moldovan lei to one Romanian leu. Software that resolves "leu" to RON, or that converts a Moldovan invoice at a Romanian rate, is wrong by a factor of roughly four, and it is wrong silently because both amounts are "lei". Moldova is not in the euro area either, so nothing here is euro. The bank identifier is drawn from moldova.finance.bankCode, so every generated IBAN names a real participant — including TR, the State Treasury, which is where every tax payment in the country goes. The 18-character account field is alphanumeric in the registry and real accounts use that: MD07VI225100000105529MDL ends in the currency code, MD10TRGAAA14518101000000 opens with letters. This file generates the account as 18 digits, which is a valid subset of the allowed field. VERIFIED BOTH WAYS against four published Moldovan IBANs — MD24AG000225100013104168 (maib), MD70ML000002224309005610 (Moldindconbank), MD07VI225100000105529MDL (Victoriabank) and MD10TRGAAA14518101000000 (State Treasury): the same fold that generates these accepts all four with remainder 1, and rejects each of them with a single character altered.
generator: tdc
---
<sequence name="bank"><gen type="template" value="moldova.finance.bankCode"/></sequence>
<sequence name="account"><gen type="regex" value="[0-9]{18}"/></sequence>
<sequence name="iban"><compute>
  <let name="bban"><concat><field name="bank"/><field name="account"/></concat></let>
  <!-- ISO 13616: move the country code and a "00" placeholder to the end. -->
  <let name="rearranged"><concat><use name="bban"/><str v="MD"/><str v="00"/></concat></let>
  <!-- The bank identifier is letters, so base-36 turns AG into 1016 before the fold. -->
  <let name="digits"><join><each>
    <over><use name="rearranged"/></over>
    <do><encode as="base36"><current/></encode></do>
  </each></join></let>
  <!-- Horner fold, so the 26-digit value never has to exist as one number. -->
  <let name="rem"><reduce>
    <over><use name="digits"/></over>
    <init><int v="0"/></init>
    <do><mod><add><multiply><acc/><int v="10"/></multiply><current/></add><int v="97"/></mod></do>
  </reduce></let>
  <let name="check"><pad width="2" fill="0"><subtract><int v="98"/><use name="rem"/></subtract></pad></let>
  <result><concat><str v="MD"/><use name="check"/><use name="bban"/></concat></result>
</compute></sequence>
<data>${{iban}}</data>
