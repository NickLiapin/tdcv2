description: Nepali postal code — FIVE digits, and every one of the 753 values this address can produce is a code the Department of Postal Services actually publishes, not a well-formed guess. NOT a hand-kept list: it is sliced out of nepal.geo.localLevelWithPostalCode, so the code and the place it belongs to can never drift apart. READ THIS BEFORE COMPARING IT WITH ANY OTHER NEPAL DATASET. Nepal renumbered its postcodes, and the codes almost every dataset still carries — Kathmandu 44600, Pokhara 33700, Lalitpur 44700, Bhaktapur 44800 — are from the scheme introduced in November 1991, whose first digit was one of the 5 DEVELOPMENT REGIONS and whose next two picked a district out of 75. The 2015 constitution abolished the development regions and made the districts 77, so those codes address a country that no longer exists, and the Department has replaced them with codes that read straight off the federal structure: digit 1 is the province (1 Koshi to 7 Sudurpashchim), digits 2-3 the district within it, digits 4-5 the local level within that district. Kathmandu Metropolitan City is 30608 in the current directory. There is a seven-digit form too — the same five digits plus a two-digit ward, so Kathmandu's wards run 3060801 to 3060832 — and it is NOT generated here, because ward counts vary from 5 to 33 between local levels and appending a random two-digit ward would overshoot most of them; a config needing a ward must pair the code with its own ward ceiling. THERE IS NO CHECK DIGIT AND THE CODE SPACE IS DENSE, which is worth a number: of the 33,885 possible single-digit changes to the 753 published codes, 12,998 — 38.4 per cent — land on ANOTHER REAL NEPALI POSTCODE, in a different district or a different province. So a typed Nepali postcode has better than one chance in three of silently addressing somewhere else, no arithmetic will catch it, and the only validation is membership of this list. No Nepali postcode begins with 0 (the provinces are numbered from 1), so a five-digit numeric column will not silently eat a leading zero — the trap the neighbouring Indian PIN sets and the Sri Lankan code sets. The old 1991 codes are deliberately absent: they are still accepted by some systems in transition and still printed on a lot of stationery, but they are not what the postal service publishes, and shipping both schemes in one address would make the pack ambiguous about which country it is describing.
