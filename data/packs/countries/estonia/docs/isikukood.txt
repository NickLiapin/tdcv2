address: estonia.docs.isikukood
description: The Estonian personal identification code (isikukood) — 11 digits, and the single identifier that Estonian life runs on: it is the tax number, the health-insurance number, the driving-licence key, the e-mail address at eesti.ee and the login to every state service, so unlike a country that keeps separate numbers for separate purposes, ONE number here joins everything. Structure: a first digit carrying century AND sex together (1/2 = born in the 1800s, 3/4 = 1900s, 5/6 = 2000s, 7/8 = 2100s; odd = male, even = female), then YYMMDD, then a 3-digit serial separating people born on the same day, then a modulus-11 check digit. Compare the Finnish hetu across the gulf, which marks the century with a punctuation character and closes with a letter from a 31-symbol table — here everything is a digit and the century rides on the same digit as the sex, so stripping the sex from an Estonian code destroys the century with it. THE CHECK IS TWO-PASS, which is the part implementations get wrong: weights 1,2,3,4,5,6,7,8,9,1 over the first ten digits first, and ONLY if that remainder is 10 do the weights shift to 3,4,5,6,7,8,9,1,2,3; if the second pass also gives 10 the check digit is 0. About one code in eleven takes the second pass, so a single-vector implementation accepts and rejects correctly for ten codes out of eleven and then fails on the eleventh — which looks like bad data rather than a bad validator. Verified against published numbers: the Estonian Wikipedia worked example 37605030299 (first pass, remainder 9) and SK ID Solutions' Smart-ID demo code 30303039914 are accepted, and their Mobile-ID demo codes 60001019947 and 60001017754 are the second-pass case — first pass 10 both times, second pass 7 and 4, which are the check digits they carry. The serial here is drawn 000-399 rather than 000-999 because Estonia records roughly forty births a day, so a real same-day serial is small.
generator: tdc
locale: et

<sequence name="dob"><gen type="date" from="1900-01-01" to="2025-12-31" format="YYYYMMDD"/></sequence>
<sequence name="sex"><gen type="text" value="0,1"/></sequence>
<sequence name="serial"><gen type="regex" value="[0-3][0-9]{2}"/></sequence>
<sequence name="isikukood"><compute>
  <!-- The drawn calendar date arrives as YYYYMMDD; the code carries YYMMDD. -->
  <let name="year"><to_number><slice from="0" to="4"><field name="dob"/></slice></to_number></let>
  <let name="yymmdd"><slice from="2" to="8"><field name="dob"/></slice></let>
  <!-- Century base: 1 = 1800s, 3 = 1900s, 5 = 2000s. Only 3 and 5 are produced.
       The sex bit is added on top: 0 = male (odd digit), 1 = female (even digit). -->
  <let name="base">
    <choose>
      <when><test><greater_than><use name="year"/><int v="1999"/></greater_than></test><then><int v="5"/></then></when>
      <otherwise><int v="3"/></otherwise>
    </choose>
  </let>
  <let name="cs"><add><use name="base"/><to_number><field name="sex"/></to_number></add></let>
  <let name="body"><concat><use name="cs"/><use name="yymmdd"/><field name="serial"/></concat></let>
  <!-- Pass 1: weights 1..9 then 1 over the 10 body digits. -->
  <let name="c1"><mod><reduce>
    <over><use name="body"/></over>
    <init><int v="0"/></init>
    <do><add><acc/><multiply><current/>
      <at><in><list v="1,2,3,4,5,6,7,8,9,1"/></in><index><current_index/></index></at>
    </multiply></add></do>
  </reduce><int v="11"/></mod></let>
  <!-- Pass 2 (used only when pass 1 gives 10): weights shifted to 3..9 then 1,2,3. -->
  <let name="c2"><mod><reduce>
    <over><use name="body"/></over>
    <init><int v="0"/></init>
    <do><add><acc/><multiply><current/>
      <at><in><list v="3,4,5,6,7,8,9,1,2,3"/></in><index><current_index/></index></at>
    </multiply></add></do>
  </reduce><int v="11"/></mod></let>
  <let name="check">
    <choose>
      <when><test><equals><use name="c1"/><int v="10"/></equals></test>
        <then><choose>
          <when><test><equals><use name="c2"/><int v="10"/></equals></test><then><int v="0"/></then></when>
          <otherwise><use name="c2"/></otherwise>
        </choose></then>
      </when>
      <otherwise><use name="c1"/></otherwise>
    </choose>
  </let>
  <result><concat><use name="body"/><use name="check"/></concat></result>
</compute></sequence>
<data>${{isikukood}}</data>
