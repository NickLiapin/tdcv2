address: georgia.phoneLandline
description: Georgian fixed line in E.164 form — +995, a real geographic area code from georgia.phoneAreaCode, and a subscriber block sized to fit the closed nine-digit plan: seven digits behind Tbilisi's two-digit 32, six behind every three-digit provincial code. The generator branches on the LENGTH of the drawn code rather than on a hard-coded list, which is why adding a code to georgia.phoneAreaCode needs no change here. The subscriber block is generated starting with 2, which is the opening digit of the published fixed-line numbers this file was checked against (Tbilisi's +995 32 2XX XX XX being the familiar case); ComCom does not publish its per-block allocations, so the leading 2 is an observed pattern and everything after it is unconstrained. Fixed lines are a shrinking minority of Georgian connections — see georgia.phone — so a person table where most rows carry a landline is not modelling Georgia.
generator: tdc
