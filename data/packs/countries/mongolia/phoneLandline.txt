address: mongolia.phoneLandline
description: Mongolian fixed line in E.164 form — +976, a real geographic code from mongolia.phoneAreaCode, and a subscriber block sized to fit the closed eight-digit plan: six digits behind Ulaanbaatar's two-digit 11, four behind every four-digit provincial 70NN. The generator branches on the LENGTH of the drawn code rather than on a hard-coded list, which is why adding a code to mongolia.phoneAreaCode needs no change here. There is no trunk prefix to strip and none to add: Mongolia's plan is closed and eight digits, so the number a Mongolian dials at home is the same eight digits that follow +976, and unlike Georgia or Russia there is no leading 0 in the domestic form. Written without separators here; Mongolian practice writes the capital's as 11-310081 and an aimag's as 7037-1234, which is the same digits with a hyphen after the code. The subscriber block is unconstrained: the CRC publishes the leading digit of the plan but not its per-block allocations, so nothing narrower than "four or six digits" can be claimed. Fixed telephony is marginal in Mongolia — there are roughly 4.8 million active mobile subscriptions against a population of 3.5 million, and a rural household typically has no landline at all — so a landline column should be sparse.
generator: tdc
