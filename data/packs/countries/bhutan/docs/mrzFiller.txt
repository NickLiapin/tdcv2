description: The ICAO 9303 filler character '<', fourteen of them — the width of the optional-data field of a TD3 machine-readable zone. IT IS HERE FOR A HOUSEKEEPING REASON AND NOT A BHUTANESE ONE: the run is NAMED, so a config draws it by address instead of repeating a literal and the width is stated in one place. Nothing forces it — a config can hold the character directly, `<gen type="text" value="<<<<<<<<<<<<<<"/>` emits fourteen of them, and `<` is an ordinary character in an attribute value. An earlier version of this note claimed the opposite, that the character could not be produced from a config at all; it could, and the claim is gone. bhutan.docs.passportMrz draws the run from here and slices single characters off it to pad the document-number field. Nothing about Bhutan is encoded here; the filler is identical on every ICAO travel document in the world, and Laos and Myanmar keep the same file for the same reason.
