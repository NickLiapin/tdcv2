address: vietnam.finance.bankWithCode
description: THE SOURCE OF TRUTH for Vietnam's banks. Each line is the 6-digit Napas bank identification number, one space, then the bank's common name — "970436 Vietcombank". vietnam.finance.bank and vietnam.finance.bankCode are both sliced out of this list, so the name and the code cannot drift apart. The BIN is the code that actually routes a domestic transfer: it is what a VietQR / Napas 247 payload names the receiving bank by, and it is the nearest thing Vietnam has to a sort code. Domestic BINs almost all sit in the 9704xx block. This is NOT a SWIFT/BIC and NOT the 8-digit CITAD interbank code, which is a different identifier for the same banks. Four struggling banks were compulsorily transferred to stronger owners in 2024-2025 and some were renamed since; their BINs did not change, and the names here are the ones the published BIN table carries. Values are mostly Latin brand names, but Vietnamese full names carry stacked diacritics (a vowel modifier plus a tone on one letter) — see vietnam.geo.provinceWithCode for what that does to naive normalisation.
locale: vi
