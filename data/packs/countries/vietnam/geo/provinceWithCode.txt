description: THE SOURCE OF TRUTH for Vietnam's provinces. Each line is the official 3-digit province code, one space, then the province name — "079 Hồ Chí Minh". This file exists so the code and the name cannot drift apart: vietnam.geo.province and vietnam.geo.provinceCode are both generated from this one list by slicing it, and vietnam.docs.cccd draws its province code from vietnam.geo.provinceCode. Edit a line here and all three follow; there is no second list to keep in step. The codes are the published administrative-division codes (mã đơn vị hành chính) of the General Statistics Office, which is the same table Thông tư 07/2016/TT-BCA prescribes for the first three digits of a CCCD. THE SET IS THE 63 UNITS AS THEY STOOD UNTIL 30 JUNE 2025. On 1 July 2025 Vietnam merged its provinces down to 34 units; the 63-entry table is kept deliberately, because a CCCD is not reissued when provinces merge and every card in circulation carries a code from this table. See vietnam.geo.province for what that means if you want today's map. Values are Vietnamese: Latin letters that carry up to two marks at once — a vowel modifier (ă â ê ô ơ ư) and a tone (à á ả ã ạ) — so "Đắk Lắk" and "Hồ Chí Minh" hold precomposed code points (NFC) that naive ASCII-folding, NFD round-trips and byte-length checks all get wrong.
locale: vi
