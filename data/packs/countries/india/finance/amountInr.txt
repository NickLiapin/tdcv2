---
address: india.finance.amountInr
description: A rupee amount written the way India writes one — 12,34,567.00 and not 1,234,567.00. The Indian system groups the last THREE digits, then every TWO after that, because the place names go thousand, lakh (1,00,000), crore (1,00,00,000), arab; the international system groups by threes all the way up because its names go thousand, million, billion. This is the single most common thing a money column gets wrong about India, and it is not a display preference: an Indian invoice, bank statement or annual report is grouped this way, and 10,00,000 and 1,000,000 are the same number written by two different conventions. The rule implemented below is: put a separator before a digit when at least three digits follow it including itself and the count of remaining digits minus three is even. The rupee sign is left off so the value drops straight into a numeric column; prefix it in the config if the output wants one. Amounts run from four to nine digits before the decimal, so the set spans thousands to tens of crores.
generator: tdc
locale: en
---
<sequence name="digits"><gen type="regex" value="[1-9][0-9]{3,8}"/></sequence>
<sequence name="paise"><gen type="regex" value="[0-9]{2}"/></sequence>
<sequence name="amount"><compute>
  <let name="len"><length><field name="digits"/></length></let>
  <let name="grouped"><join><each>
    <over><field name="digits"/></over>
    <do>
      <!-- Digits still to come, counting this one. -->
      <let name="rem"><subtract><use name="len"/><current_index/></subtract></let>
      <choose>
        <!-- Never a separator before the very first digit. -->
        <when><test><equals><current_index/><int v="0"/></equals></test><then><current/></then></when>
        <otherwise><choose>
          <!-- The last three digits are one group: no separator inside them. -->
          <when><test><less_than><use name="rem"/><int v="3"/></less_than></test><then><current/></then></when>
          <!-- Above those three the groups are TWO wide, so a separator lands
               wherever (rem - 3) is even: 3 -> the thousand mark, 5 -> the lakh
               mark, 7 -> the crore mark, and so on. -->
          <when><test><equals><mod><subtract><use name="rem"/><int v="3"/></subtract><int v="2"/></mod><int v="0"/></equals></test>
            <then><concat><str v=","/><current/></concat></then></when>
          <otherwise><current/></otherwise>
        </choose></otherwise>
      </choose>
    </do>
  </each></join></let>
  <result><concat><use name="grouped"/><str v="."/><field name="paise"/></concat></result>
</compute></sequence>
<data>${{amount}}</data>
