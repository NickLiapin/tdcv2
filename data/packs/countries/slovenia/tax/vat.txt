address: slovenia.tax.vat
description: Slovenian VAT number / ID za DDV — SI plus the taxpayer's 8-digit davčna številka, so this file and slovenia.tax.davcnaStevilka share one arithmetic (7-digit base, weights 8,7,6,5,4,3,2, mod 11). Slovenia issues no separate VAT number; the prefix is the whole difference, which is why a Slovenian invoice shows the bare 8 digits domestically and SI+8 to an EU counterparty. VAT has been charged in EURO since 1 January 2007, when Slovenia became the first of the ten 2004 entrants to adopt the euro and dropped the tolar. Earlier versions of this file resolved the mod-11 edge the JMBG way (remainder 0 to check 0, remainder 1 redrawn); FURS specifies the reverse — remainder 1 gives a check digit of 0, remainder 0 takes the base out of the pool — so roughly one in eleven generated numbers used to be one FURS never issues. Verified against the published VAT numbers SI82646716 (Krka), SI94018154 (Mercator), SI80040306 (Zavarovalnica Triglav), SI44814631 (Zavarovalnica Sava), SI80267432 (Petrol) and SI89190033 (Luka Koper).
generator: tdc
