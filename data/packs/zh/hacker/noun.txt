description: Technical nouns in the Taiwanese register, and this is where Traditional Chinese diverges from the mainland most sharply — almost every line differs as a word, not merely as a glyph. A server is a 伺服器 and never a 服務器, data is 資料 and never 數據, a file is a 檔案 and never a 文件, memory is 記憶體 and never 內存, a hard disk is a 硬碟 and never a 硬盤, a thread is an 執行緒 and a process a 行程. A port is a 連接埠, a packet a 封包, a library a 函式庫, a package a 套件, a container image a 映像檔, and a cluster a 叢集. Converting a mainland technical document character by character produces text that no engineer in Taipei would write.
