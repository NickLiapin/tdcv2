# user — личная песочница пользователя

Сюда пользователь кладёт **свои** генераторы и данные. Адрес: `user.<...>` —
например `user.test.foo.bar`. Структуру внутри пользователь выбирает сам.

**Важно про обновления.** В поставляемой библиотеке эта папка живёт НЕ внутри
пакета (иначе `npm update` её бы стёр), а в директории самого пользователя (его
проект или `~/.tdc/`), которая подключается как источник данных
(`--data-path` / `dataPaths`). Поэтому она **переживает любые обновления**.
Здесь, в dev-репозитории, она — заготовка/пример.
