description: ЭЦГИЙН НЭР — the father's name in the genitive, which is what occupies the surname slot on a Mongolian form. IT IS NOT A FAMILY NAME AND DOES NOT BEHAVE LIKE ONE. Mongolians have no inherited surname in the European sense: the first element of an official name is the father's own given name put into the genitive case, so Бат's son Дорж is Батын Дорж, and Дорж's own son Ганбат is Доржийн Ганбат. The element therefore CHANGES EVERY GENERATION; siblings share it and cousins do not. Three consequences a config must respect. FIRST, the real name is the GIVEN name: Mongolians are addressed, introduced, listed in a directory, printed on a team sheet and alphabetised by their given name, so a table sorted on this column is sorted on nothing meaningful. SECOND, in ordinary written use the эцгийн нэр is reduced to its first letter and a full stop — Б.Дорж, Д.Ганбат — and the unabbreviated form appears mainly on documents; person/male/initialName.tdc and person/female/initialName.tdc generate that everyday shape. THIRD, THERE IS NO person/female/lastName.txt AND THAT ABSENCE IS THE DESIGN: Mongolian has no grammatical gender at all, and a daughter carries her father's name in exactly the same genitive form as her brother — Батын Оюун beside Батын Дорж — so a feminine file would be a byte-for-byte copy of this one and would only invite a config to imply a distinction the language does not make. SEPARATELY there is a third name, the ОВОГ or clan name (Боржигин, Бэсүд, Сартуул, Хатагин, Олхонууд and so on), abolished in 1925 and re-registered from 2000; it sits in its own field on the identity card, is almost never used in daily life, and is not this file either. THE GENITIVE IS NOT ONE SUFFIX: a back-vowel stem ending in a consonant takes -ын (Бат to Батын, Намбар to Намбарын), a front-vowel stem or one ending in ж, ч, ш, г or к takes -ийн (Дорж to Доржийн, Чимэд to Чимэдийн, Нацаг to Нацагийн), a stem ending in a long vowel or diphthong takes -гийн (Ухнаа to Ухнаагийн, Хорлоо to Хорлоогийн, Цахиа to Цахиагийн), and one ending in -й just adds -н (Лувсанназрай to Лувсанназрайн). Names ending in -н vary genuinely in real usage — Дамдины Сүхбаатар and Балингийн Цэрэндорж are both heads of state and both forms are correct — so apart from the attested Дамдины this file avoids them rather than guessing. The weights are RANK-DERIVED Zipf decay, not measured: no Mongolian name frequency table is published, and the frequency of this column is in any case the frequency of male given names one generation ago.
locale: mn
weighted: true
