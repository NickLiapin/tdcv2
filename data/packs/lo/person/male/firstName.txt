description: Lao man's given name — and in Lao this is the name that matters. A Lao person is addressed, listed and alphabetised by the GIVEN name, not the surname (see person/lastName.txt), so this is the column that fills a salutation, a name badge and a directory sort. Given names are Pali-Sanskrit in origin and are still read as transparent words: ບຸນ- is 'merit', ຄຳ- 'gold', ທອງ- 'gold/bronze', ສີ- 'splendour', ໄຊ- 'victory', ສົມ- 'fulfilled', ພູ- 'mountain', ວົງ- 'lineage', ແສງ- 'light'. Several entries are genuinely UNISEX — ວົງເດືອນ, ສີສະຫວາດ, ດວງໃຈ, ຄຳຜຸຍ, ບຸນນາລີ — so an overlap with person/female/firstName.txt is deliberate and is not a duplication bug. Note that Lao writes without spaces between words, so the space in a full name is a genuine field boundary between given name and surname and is one of the very few spaces in a Lao text that a tokeniser may trust. THE COUNTS ARE A NOMINAL RANK CURVE: Laos publishes no given-name frequency table.
