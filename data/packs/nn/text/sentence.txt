description: Filler sentences in Nynorsk. Handwritten: Project Gutenberg holds no Nynorsk book at all. The language search l.nn returns "No records found.", and the 23 books Gutenberg files under the Norwegian code no are Ibsen, Hamsun, Wergeland and Undset — every one of them Bokmål or Riksmål, the Dano-Norwegian tradition that Nynorsk was built as an alternative to. Arne Garborg, the great Nynorsk novelist, is on Gutenberg only in Esperanto and Finnish translation, and Olav Duun only in English. Building a Nynorsk corpus out of those 23 books would have produced a text/ directory in the wrong written standard, which is exactly the failure this pack exists to avoid, so these files are written by hand instead. If a real Nynorsk corpus is ever wired into data/scripts/build-text-corpus.mjs, this file should be replaced rather than extended. Each line is one complete, grammatical Nynorsk sentence with a full stop, written to cover ordinary registers — statement, question, narrative past — and to exercise the forms that separate the standard: the -ar present tense, the a-ending past participle, the feminine definite in -a, and the pronouns eg, me, ho and dei.
locale: nn
