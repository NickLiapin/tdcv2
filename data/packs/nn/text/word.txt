description: Filler words in Nynorsk, for lorem-ipsum style text. Handwritten: Project Gutenberg holds no Nynorsk book at all. The language search l.nn returns "No records found.", and the 23 books Gutenberg files under the Norwegian code no are Ibsen, Hamsun, Wergeland and Undset — every one of them Bokmål or Riksmål, the Dano-Norwegian tradition that Nynorsk was built as an alternative to. Arne Garborg, the great Nynorsk novelist, is on Gutenberg only in Esperanto and Finnish translation, and Olav Duun only in English. Building a Nynorsk corpus out of those 23 books would have produced a text/ directory in the wrong written standard, which is exactly the failure this pack exists to avoid, so these files are written by hand instead. If a real Nynorsk corpus is ever wired into data/scripts/build-text-corpus.mjs, this file should be replaced rather than extended. The list is real Nynorsk vocabulary rather than a scramble: the function words (ikkje, kva, korleis, berre, mykje, eg, me, ho, dei) are the ones that mark the standard, and the content words are ordinary nouns, verbs and adjectives of landscape, home, work and weather.
locale: nn
