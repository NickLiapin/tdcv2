description: Technical abbreviation. These keep their Latin spelling in Sindhi technical writing exactly as they do in Persian, Polish or Japanese, and a Sindhi manual that spelled HTTP out in Sindhi letters would be unreadable to the engineers using it. The practical consequence is a bidirectional one: Sindhi runs right to left, so every string here is an embedded left-to-right run inside its line, and any renderer consuming this pack has to apply the Unicode bidirectional algorithm properly. A naive implementation that reverses the line will put the letters of HTTP back to front, and a naive one that does not reverse anything will put the abbreviation at the wrong end of the sentence.
locale: sd
