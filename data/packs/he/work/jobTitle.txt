description: Israeli job titles across sectors, given in the MASCULINE SINGULAR. This is the thing about Hebrew a config cannot infer, so it is set out here in full. Hebrew marks gender on the noun, the adjective and the verb, so a job title is not gender-neutral the way an English one is: מהנדס is a male engineer and מהנדסת a female one, and the sentence around it has to agree too (המהנדס כתב / המהנדסת כתבה). There is no neutral form. The masculine is shipped because it is the citation form, the form an org chart prints, and the base the feminine is derived from — usually by adding ־ת (מהנדס → מהנדסת, טכנאי → טכנאית) or ־ה (רופא → רופאה), with a handful invariable (מורה, שופט → שופטת). A parallel feminine file is deliberately NOT shipped: it would have to stay aligned line for line with this one, which the brief says must be done by a script and not by hand, and no such script exists yet. Worth knowing separately: Israeli law requires job advertisements to address both genders, so real Israeli listings write the doubled form — מהנדס/ת תוכנה, מנהל/ת מוצר — and a dataset meant to look like job ads should compose that shape rather than use these values raw.
locale: he
