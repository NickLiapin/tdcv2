description: Burmese woman's name, weighted. EVERY STRING HERE IS A WHOLE NAME, NOT A GIVEN NAME. Burmese has no family names, so there is nothing for this to be the first half of — see person/lastName.txt, which explains at length what that file actually contains and why joining the two is a Western form filling itself in rather than a Burmese person naming themselves. A Burmese name is one to four syllables long and is chosen, not inherited; siblings share nothing, and a wife's name does not change on marriage. Names have grown longer over time, so a single syllable (လှ, နု, သန့်) reads as an older generation and four syllables (အောင်ကောင်းမြတ်) as a younger one. REDUPLICATION IS REAL AND VERY COMMON — ကျော်ကျော်, ထွန်းထွန်း, မြမြ, နီနီ are ordinary names, not diminutives. HONORIFICS ARE NOT PART OF THE NAME and are not in this list: ဦး, ဒေါ်, ကို, မ, မောင် live in person/prefix.txt because they change with the speaker's age and status relative to yours, so the same person is ကိုအောင် to a friend and ဦးအောင် at sixty. THE FIRST LETTER IS NOT FREE: a Burmese child is traditionally named from the DAY OF THE WEEK IT WAS BORN, and the day fixes the class of consonant the name must start with. Sunday takes the vowels and အ; Monday က ခ ဂ ဃ င; Tuesday စ ဆ ဇ ဈ ည; Wednesday လ ဝ; Thursday ပ ဖ ဗ ဘ မ; Friday သ ဟ; Saturday တ ထ ဒ ဓ န. Wednesday afternoon is a separate eighth day, ရာဟု, and takes ယ ရ. This list is GROUPED IN THAT ORDER, Sunday first, so a config that wants day-consistent names can slice it rather than filter it — and a config that draws at random is producing people whose names and birthdays disagree, which any Burmese reader will notice immediately. The practice is astrological and it is still ordinary: the eight posts around a pagoda are the eight days, and a Burmese person knows their birth day the way a Westerner knows their star sign. The one systematic difference from the male list is that a woman's name is far more likely to be a REDUPLICATION (ခင်ခင်, မြမြ, နုနု, ရီရီ, စုစု, ဝါဝါ) and far more likely to open with ခင်, မ, မြ, နှင်း, စု or သီ. Neither pattern is a rule: မိုး, ဇင်, ခိုင်, ထက်, ဝင်း, အေး and ကြည် are genuinely unisex, so this list DELIBERATELY OVERLAPS with the male one. A NAME DOES NOT CHANGE ON MARRIAGE. A Burmese woman keeps her own name for life — there is no maiden name and no married name, because there is no family name to take — so a dataset that derives a wife's name from a husband's is modelling a Western convention that Myanmar does not have. The weights are a gentle tiered curve and not measured frequencies; no Myanmar name-frequency data exists.
