description: Czech surname in the MASCULINE form. Czech surnames inflect for gender far more thoroughly than most European languages: nearly every one takes -ova in the feminine, including foreign ones (Novak -> Novakova, Svoboda -> Svobodova), and adjectival surnames swap -y for -a (Cerny -> Cerna). The feminine list is person/female/lastName, derived line for line by data/scripts/build-cs-surnames.mjs - draw the same row index from both for one family. Only the -i type (Krejci, Koci, Dolejsi) and the genitive-plural -u type (Janu, Petru, Martinu) are identical for both genders. A Czech full name carries a single surname, so draw once. Weights are a rank-decay curve, not measured shares: Czech surnames are spread gently (Novak is under 1% of the population), so no name dominates.
weighted: true
