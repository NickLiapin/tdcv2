# Male given names again — but ordered by how common they were among FATHERS.
#
# This file holds no patronymics. A patronymic is derived from the father's given
# name by rule (see masculinePatronymic in build-ru-names.mjs), so writing the
# forms down a second time only creates a second list to keep in step. What cannot
# be derived is the ORDER: a patronymic names a man a generation older, so
# Николаевич and Петрович are common while Николай and Пётр are not names given to
# children today. That skew is the only thing this file carries.
#
# It may be a PREFIX. Any given name missing here still gets a patronymic — it just
# lands after this list, in the order of first-names-male.txt. So adding a name
# there is never silently lost; it is only unranked, which for a rare name is right.
#
# Every name here must be a real entry in first-names-male.txt, and the builder
# refuses one that is not: a father whose name the pack does not know is a typo.
