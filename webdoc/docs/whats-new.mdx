# What's new

What changed in TDC that you can see — a new command or flag, a new check, something that
now works differently — newest first, each with a link to where the docs explain it now.
Changes inside the engine that alter nothing you write or read are left out; every change is
in the [changelog](https://github.com/NickLiapin/tdcv2/blob/main/CHANGELOG.md).

## 9 November 2026 — version 0.4.0

The `http` generator now works at any size. If you wrote a service for it, the second and
third items below need a change on the service's side, which is why the version is 0.4.0.

- **`http` sends a column in batches.** One request carries `batch=` rows, 10,000 by default,
  and rows are written as the answers arrive. The whole column used to go in one request, and
  a run stopped at about a million rows. A gigabyte of hashed rows now runs in every package.
  `parallel=` puts several batches on the wire at once. A value for either that is not a whole
  number above zero is `TDC313`. →
  [Batches](./generators/http.mdx#batches-one-request-per-ten-thousand-rows)
- **A source service sends `X-TDC-Offset` back.** Each request now says which rows it covers:
  `X-TDC-Offset` is the first row and `X-TDC-Total` is the length of the run. A source — a
  service with no `in=` — returns the offset it received in a header of the same name, or a run
  longer than one batch stops. A handler needs no change. →
  [The contract](./generators/http.mdx#the-contract-your-service-implements)
- **The `secret=` signature covers the offset and the total.** A service that checks signatures
  adds the two lines: `timestamp \n seed \n count \n offset \n total \n body`. →
  [Proving the request came from TDC](./generators/http.mdx#proving-the-request-came-from-tdc)
- **A column that reads an `http` answer gets the answer.** `if="Hash == ''"`, a `<switch>` on
  the answer, or a line that prints it used to see an empty string. A call inside a `<mix>` or
  `<switch>` case, an `if=` branch, or a compound's field prints its answer, and `parent=` on an
  `http` sequence blanks the rows the parent leaves empty. → [The `http` generator](./generators/http.mdx)
- **An `http` column cannot be a member of `<uniq>` or `<distinct>`, `TDC314`.** A `<uniq>`
  group moved answers between rows, so a hash could land beside another row's password. Put the
  group around the columns the service reads, and the `http` column follows them. →
  [What it does not promise](./generators/http.mdx#what-it-does-not-promise)
- **`uniq="true"` on an `http` sequence checks the answers.** It used to be refused with
  `TDC218`. The run reads every answer before it writes the first row, and stops at the first
  repeat, naming both rows. →
  [What it does not promise](./generators/http.mdx#what-it-does-not-promise)
- **In TypeScript, `toString()` and `writeFile()` work with `http`.** They used to throw and
  point you to `toStringAsync()`, which stays for older code. `usesHttp()` in TypeScript, Python,
  and Java now finds a service called from a case or a branch. →
  [Terminal methods](./bindings/typescript.mdx#terminal-methods)

## 4 November 2026 — version 0.3.7

- **A value can be written in single quotes.** `value='say "hi"'` holds a `"` exactly as
  written. Nothing inside a value is escaped, so the other kind of quote is how you write one.
  It works in every tag, and `tdcv2 format` keeps the quotes you chose. →
  [Writing a value](./reference/attributes.mdx#writing-a-value)
- **Parquet types a field by the field it reads.** `${{Dept.id}}`, read through a pool, comes
  out as the `int64` its `increment` makes, not as text. So does a compound sequence's field,
  such as `${{Address.zip}}`. →
  [You can skip `type=`](./guides/typed-output-parquet.mdx#you-can-skip-type--tdc-infers-it)
- **A Parquet column the config may leave empty is nullable.** A `parent=`, or a `<gen if>`
  with no fallback branch, used to stop the run at the first empty row. Those rows are `null`
  now. → [You can skip `type=`](./guides/typed-output-parquet.mdx#you-can-skip-type--tdc-infers-it)
- **`missing_as` keeps a Parquet column as text**, because the word it prints is what the cell
  holds. →
  [Three cases where inference is skipped](./guides/typed-output-parquet.mdx#three-cases-where-inference-is-deliberately-skipped)
- **A `timeseries` or `pattern` inside a `<mix>` case or under `parent=` keeps the run's time
  axis.** Row 7 reads the series at 7, whichever branch produced it, so a rare "sensor stuck"
  branch punches holes in a wave without scrambling it. →
  [`timeseries` details](./generators/timeseries.mdx#details)
- **`uniq` inside a `<pool>` is measured by the pool.** The memory warning `TDC299` read the
  run's `count`, so a thousand doctors with a unique room number warned about 48 MB on a long
  run. The pool's own `count` decides now. →
  [`TDC299`](./reference/errors.mdx#formatting-and-modifiers)
- **`if=` or `default=` on a `<case>` is an error in every package**, `TDC128`. Neither was ever
  read — a `<mix>` deals cases by share, a `<switch>` by the `is=` key — and the Python, Rust,
  Java and C# packages accepted them in silence. → [`TDC128`](./reference/errors.mdx#generators)
- **`tdcv2 big.tdc | head` ends quietly** in the TypeScript and Python packages. They used to
  print an EPIPE error and exit 1 when `head` closed the pipe; they now exit 0, as the other
  three did. → [Exit codes](./reference/cli.mdx#exit-codes)

## 25 October 2026 — version 0.3.6

- **`<line each="Pool">` prints a pool record by record.** One line per record, every field read
  as `${{Pool.field}}`, so a lookup table comes out of the same config as the rows that point at
  it. The positions `Pool._first`, `Pool._last` and `Pool._item` count the lines actually
  printed, which is what puts a comma between JSON objects and not after the last one. →
  [A whole pool, record by record](./constructs/relational-tables.mdx#a-whole-pool-record-by-record)
- **`<group>` keeps several lines together.** `<group each="Depts">` prints its lines once per
  department, and a group inside it prints that department's doctors — a nested JSON document from
  one config. Without `each`, its `if=` keeps or drops all its lines at once. →
  [Several lines per element](./constructs/relational-tables.mdx#several-lines-per-element-group)
- **The `json` filter.** `${{Name | json}}` writes a JSON string with the escaping done, or `null`
  for an empty value; `${{Tags | json:;}}` writes a list as a JSON array. A list printed without
  its separator gets a warning, `TDC312`. →
  [`json`](./guides/masks-and-case.mdx#json--a-complete-json-value)
- **`plus=` reads the distance from a column.** `<gen type="date" of="Start" plus="Length m">`
  ends each appointment its own length after it starts. →
  [A distance read from another column](./generators/date.mdx#a-distance-read-from-another-column)
- **The `if=` of an `each` line decides element by element.** `<line each="Orders" if="Orders >
  5000">` prints the large orders only; it used to keep or drop the whole line. →
  [What's visible inside an `each` line](./constructs/relational-tables.mdx#whats-visible-inside-an-each-line)
- **Fixture lines are checked, and their `if=` is read.** A misspelled `${{Name}}` in `<before>`
  is an error in `check` instead of reaching the file as written. →
  [Fixtures](./core-concepts/output-formatting.mdx#fixtures--text-around-the-records)
- **Health identifiers with real check digits:** the US NPI, Germany's KVNR and LANR, France's
  RPPS and FINESS, Brazil's CNS. →
  [National tax and document numbers](./reference/identifiers.mdx#national-tax-and-document-numbers)
- **US and Canadian phone numbers use every area code in service**, with 555-0100 to 555-0199,
  the line numbers reserved for fiction. Every US number used to start `+1 202 555`. →
  [Phone numbers](./reference/identifiers.mdx#phone-numbers)
- **The pack registry holds %%TDC_PACK_SETS%% bundles.** Traditional Chinese, Uzbek, Montenegrin,
  Breton, Sindhi, four more languages and 46 countries can be downloaded now, and `tdcv2 pack list` names countries as
  names: United States, not "Usa". → [`pack list`](./data-packs/installing-packs.mdx#pack-list--see-the-catalog)
- **Rust and C#:** a pack whose `<valid>` check rejects a value now redraws it the way the other
  three do. Eleven shipped packs, the ISO 6346 container code and Slovenian postal codes among
  them, gave different values there. → [`<valid>`](./compute/conditionals.mdx#valid--reject-and-retry)
- **AI agents.** Claude Code, Codex, Cursor, VS Code and Gemini CLI can write and run TDC configs
  for you, through a skill and an MCP server. → [AI Agents](./ai-agents/overview.mdx)

## 17 October 2026 — version 0.3.5

- **`check` says which engine will run the config, and why.** A second line after "is valid",
  such as `runs on engine 1 (in memory): uniq="true" on "Code"` — that is where the run's memory
  goes. `--brief` leaves it out. → [`tdcv2 check`](./reference/cli.mdx#tdcv2-check)
- **`--engine 3` says when engine 1 runs the config instead.** On a running total, a statistic or
  a `uniq="true"` column it always handed the run to the in-memory engine; it now prints a note,
  so a memory reading is not quietly one of engine 1. →
  [Which engine runs your config](./guides/large-outputs.mdx#which-engine-runs-your-config)
- **Fixed: a lookup or a formula reading a `<uniq>` member saw the value from before the group
  was settled** — the day printed and the day looked up disagreed on almost every row. →
  [`<uniq>` — across separate sequences](./constructs/unique-values.mdx#uniq--across-separate-sequences)
- **Fixed: `<assert>` and `if=` read a field two or more pools deep**, such as
  `D.room.dept.dep_id`. → [How deep can it go](./pools/linking.mdx#how-deep-can-it-go)
- **Fixed: a filter inside a pool reads the fields beside it.** `filter="dept_no == want"`, with
  `want` a field of the same pool, was refused as a filter that can never match. →
  [What a name means inside `filter`](./pools/filter.mdx#what-a-name-means-inside-filter)
- **Fixed: every element of a `repeat=` is its own draw.** A repeated e-mail address no longer
  repeats one domain, and a distribution whose parameter names another column reads each row's
  own value. → [Multiple values in a cell](./constructs/multiple-values.mdx)
- **Fixed: February 29 stays February 29.** In the npm package a date bounded by or measured from
  2024-02-29 came out as March 1. →
  [A random date in a range](./generators/date.mdx#a-random-date-in-a-range)
- **Python, Rust, Java and C#:** a `<switch>` on a field of a pool record, a date measured from
  one, and `repeat=` inside a `<switch>` branch or a `<mix>` case work as they do in the npm
  package. → [Two names, one dot](./pools/overview.mdx#two-names-one-dot)

## 16 October 2026 — version 0.3.4

- **`init` can leave the examples out.** `tdcv2 init --yes --no-examples` writes the config
  and the pack folder and nothing else — for a script or an AI agent that sets up a project on
  someone's behalf. → [`--no-examples`](./data-packs/installing-packs.mdx#--no-examples--the-config-and-nothing-else)
- **`check` warns about three mistakes that used to pass in silence.** Each one ran without a
  word and gave the wrong data:
  - no `seed=` on `<env>`: every run draws a different file →
    [`seed`](./core-concepts/configuration.mdx#seed)
  - `mm` in a date format is minutes, so `YYYY-mm-DD` printed month `00`; the month is `MM` →
    [Formatting the output](./generators/date.mdx#formatting-the-output)
  - `&quot;` or another XML entity in `<data>` is printed as written →
    [`<data>` — raw text](./core-concepts/output-formatting.mdx#data--raw-text)

  They are warnings: `check` still exits with 0. A run given `--seed` has nothing to warn about,
  and a run without one prints the seed it drew instead. → [`tdcv2 check`](./reference/cli.mdx#tdcv2-check),
  codes `TDC309`–`TDC311` in the [diagnostics reference](./reference/errors.mdx)
- **A date measured from another date has its format checked.** `format="YYY"` on a date with
  `of=`/`plus=` printed `25Y` on every row; `check` now refuses it, as it does for any other
  date. → [A date measured from another date](./generators/date.mdx#an-interval-a-date-measured-from-another-date)
- **npm package: `init --locale` with no value is refused.** It used to write an `en` config
  without a word; the other four implementations already refused it. →
  [`--locale`](./data-packs/installing-packs.mdx#--locale-loc--pick-the-default-locale)
