# Tags reference

Every tag in the TDC DSL, and where each one is covered in depth.

## Structure

| Tag          | What it is                                                                                                  | See                                                             |
| :----------- | :---------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------- |
| `<!--…-->`   | A comment                                                                                                   | —                                                               |
| `<tdc>`      | The root element                                                                                            | [Configuration](../core-concepts/configuration.mdx)             |
| `<env>`      | The environment: parameters, sequences, fixtures                                                            | [Configuration](../core-concepts/configuration.mdx)             |
| `<sequence>` | A named sequence declaration                                                                                | [Sequences](../core-concepts/sequences.mdx)                     |
| `<gen>`      | A data generator                                                                                            | [Generators](../generators/overview.mdx)                        |
| `<data>`     | Inside a `<sequence>`: literal text joined into the sequence's value, or — with a `name` — a constant field | [Sequences](../core-concepts/sequences.mdx#a-composed-sequence) |
| `<compute>`  | A computed value                                                                                            | [Compute Language](../compute/overview.mdx)                     |

## Uniqueness

| Tag          | What it is                                                     | See                                               |
| :----------- | :------------------------------------------------------------- | :------------------------------------------------ |
| `<distinct>` | Fields or sequences that must differ within one row            | [No repeats within a row](../guides/distinct.mdx) |
| `<uniq>`     | A combination of sequences that must be unique across all rows | [Unique values](../constructs/unique-values.mdx)  |

`<data>` is listed twice because it reads two ways. Inside a `<line>` it is output:
literal text with `${{…}}` interpolated into it. Inside a `<sequence>` it is data:
bare, it is the glue between the generators of a
[composed sequence](../core-concepts/sequences.mdx#a-composed-sequence); with a
`name`, it is a [constant field](../core-concepts/sequences.mdx#a-constant-field) and
the only field that costs no draw.

Compute tags (the ones that go inside `<compute>`) have their own list in the
[Compute functions reference](compute.mdx).
