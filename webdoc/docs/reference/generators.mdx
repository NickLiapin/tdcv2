# Generators reference

Every `type` for [`<gen>`](../generators/overview.mdx). Each one links to its full page.

| `type`                                                  | Produces                                               |
| :------------------------------------------------------ | :----------------------------------------------------- |
| [`text`](../generators/text.mdx)                        | A value from a set — uniform or by exact `percent`     |
| [`number`](../generators/number.mdx)                    | An integer in a range, or a fixed-width digit string   |
| [`template`](../generators/template.mdx)                | Built-in realistic data and technical IDs              |
| [`file`](../generators/file.mdx)                        | Values from your own files and CSV columns             |
| [`date`](../generators/date.mdx)                        | A date or date-time in a range and format              |
| [`symbol`](../generators/symbol.mdx)                    | A string of characters from a set or named alphabet    |
| [`regex`](../generators/regex.mdx)                      | A string matching a finite regular expression          |
| [`advanced_regex`](../generators/advanced-regex.mdx)    | Regex, plus weighted choice between alternatives       |
| [`increment` / `decrement`](../generators/counters.mdx) | Rising and falling counters                            |
| [`timeseries`](../generators/timeseries.mdx)            | A time series — trend + seasonality + noise            |
| [`pattern`](../generators/pattern.mdx)                  | A distribution shaped like a drawn curve               |
| [`http`](../generators/http.mdx)                        | A value fetched over HTTP from a service you wrote     |
| [`pool`](../pools/overview.mdx)                         | One whole member of a `<pool>` — a record, not a value |
| [`running`](../generators/running.mdx)                  | A total accumulated down the column, not drawn         |
| [`stat`](../generators/stat.mdx)                        | One number over the whole run, on every row            |

## Cross-cutting attributes

These work on **any** generator (see [Masks & case](../guides/masks-and-case.mdx)):

- `case=` / `mask=` — letter case and display masks.
- `missing=` — leave a share of the cells blank.

The next two only work when the generator produces something they can act on. Everywhere
else they're ignored:

- `order=` / `cycle=` — value order: random by default, or `sequential`. Ordering walks a
  list, so it applies to [`text`](../generators/text.mdx) and
  [`file`](../generators/file.mdx). A [`number`](../generators/number.mdx) or a
  [`date`](../generators/date.mdx) draws from a range rather than a list, so it ignores
  the attribute.
- `anomaly=` — push a share of the values out of range by multiplying them. The rule is
  about the **value**, not the generator: anything that reads as a number is multiplied,
  including a numeric string from [`text`](../generators/text.mdx),
  [`file`](../generators/file.mdx) or a pack. Anything else — a name, a city — passes
  through unchanged and **without a warning**, because there is no "further out" for it.
  See [Anomalies & missing values](../guides/anomalies.mdx).

See also the [Generators overview](../generators/overview.mdx).
