# Java

Java-пакет читает **тот же `.tdc`-конфиг** и при одном и том же сиде выдаёт **тот же
результат**, что и реализации на TypeScript, Python, C# и Rust — та же межъязыковая
гарантия.

## Где взять

:::note[Пока не на Maven Central]
Java — единственная из пяти реализаций, которую ещё предстоит опубликовать. Она
завершена и проходит все кросс-языковые фикстуры, и jar даже несёт стартовые паки, так
что пока её собирают из клона:

```bash
cd java && ./gradlew build
```

Полная картина, включая отдельный jar с командной строкой, — на странице
[Установка](../getting-started/installation.mdx).
:::

## Как пользоваться

```java
var data = new TDC("users.tdc");
System.out.println(data.toString());

for (var row : data.iterate()) {
    System.out.println(row.get("Gender"));
}
```

Имена методов повторяют [TypeScript API](typescript.mdx).
