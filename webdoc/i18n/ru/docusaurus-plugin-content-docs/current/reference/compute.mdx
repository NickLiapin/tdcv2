# Справочник compute-функций

Все теги подъязыка [`<compute>`](../compute/overview.mdx), по группам. Раздел
[Язык вычислений](../compute/overview.mdx) объясняет, как они складываются вместе.

Как читать колонку «Сигнатура»: `int|str|list` — любой из трёх типов, `…` — любое число
детей, `?` — необязательный атрибут, `1` — ровно одно дочернее выражение, `—` — тег сам
по себе значения не даёт. Слоты — дети с должностью — стоят по имени в сигнатуре того
тега, которому они принадлежат.

## Литералы и ссылки

Подробно: [Язык вычислений](../compute/overview.mdx)

| Тег                                                                  | Сигнатура                  | Что делает                                                     |
| :------------------------------------------------------------------- | :------------------------- | :------------------------------------------------------------- |
| [`<int>`](../compute/overview.mdx)                                   | `v=` → `int`               | Целочисленный литерал (атрибут `v`)                            |
| [`<str>`](../compute/strings.mdx#str--строковый-литерал)             | `v=` → `str`               | Строковый литерал (атрибут `v`)                                |
| [`<list>`](../compute/lists.mdx#list--литерал-список-значений)       | `v=` или `int…` → `list`   | Литерал-список целых или из вложенных выражений                |
| [`<field>`](../compute/overview.mdx#значение-из-field--строка)       | `name=` → `str`            | Значение последовательности в области видимости — как `${{X}}` |
| [`<use>`](../compute/overview.mdx#let-и-var--не-два-вида-переменной) | `name=` → `int\|str\|list` | Значение, связанное `<let>`                                    |
| [`<let>`](../compute/overview.mdx#let-и-var--не-два-вида-переменной) | `name=` + 1 → `—`          | Назвать промежуточный результат для соседних тегов             |
| [`<current>`](../compute/lists.mdx#each--перебор-списка)             | → `int\|str`               | Текущий элемент перебора (внутри `<do>`)                       |
| [`<current_index>`](../compute/lists.mdx#each--перебор-списка)       | → `int`                    | Номер текущего элемента, с нуля                                |
| [`<acc>`](../compute/lists.mdx#reduce--свёртка-в-одно-значение)      | → `int\|str\|list`         | Накопитель (внутри `<reduce>`)                                 |

## Списки и перебор

Подробно: [Списки и перебор](../compute/lists.mdx)

| Тег                                                                | Сигнатура                                   | Что делает                                |
| :----------------------------------------------------------------- | :------------------------------------------ | :---------------------------------------- |
| [`<each>`](../compute/lists.mdx#each--перебор-списка)              | `<over>` `<do>` → `list`                    | Преобразовать каждый элемент → список     |
| [`<reduce>`](../compute/lists.mdx#reduce--свёртка-в-одно-значение) | `<over>` `<init>` `<do>` → `int\|str\|list` | Свернуть список в одно значение (`<acc>`) |
| [`<join>`](../compute/lists.mdx#join--список-в-строку)             | `list` + `sep=?` → `str`                    | Список → строка (атрибут `sep`)           |
| [`<split>`](../compute/lists.mdx#split--строка-в-список)           | `str` + `sep=` → `list`                     | Строка → список, рез по `sep` (обязателен) |
| [`<at>`](../compute/lists.mdx#at--доступ-по-индексу)               | `<in>` `<index>` + `default=?` → `int\|str` | Элемент по индексу (атрибут `default`)    |
| [`<length>`](../compute/lists.mdx#length--длина-строки-или-списка) | `str\|list` → `int`                         | Длина строки или списка                   |

## Арифметика

Подробно: [Арифметика](../compute/arithmetic.mdx)

| Тег                                                | Сигнатура           | Что делает                             |
| :------------------------------------------------- | :------------------ | :------------------------------------- |
| [`<add>`](../compute/arithmetic.mdx#add)           | `int…` → `int`      | Сумма всех детей (пусто → 0)           |
| [`<subtract>`](../compute/arithmetic.mdx#subtract) | `int…` → `int`      | Первое минус сумма остальных           |
| [`<multiply>`](../compute/arithmetic.mdx#multiply) | `int…` → `int`      | Произведение (пусто → 1)               |

| [`<mod>`](../compute/arithmetic.mdx#mod)           | `int` `int` → `int` | Остаток по Евклиду, всегда ≥ 0         |

| [`<replace>`](../compute/strings.mdx#replace--заменить-все-вхождения)                                                                                       | `str` + `from=` `to=` → `str`          | Заменить все вхождения (`from`, `to`)       |
| [`<trim>`](../compute/strings.mdx#trim--убрать-крайние-пробелы)                                                                                             | `str` → `str`                          | Убрать крайние пробелы                      |
