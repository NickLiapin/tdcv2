# Справочник атрибутов

Все атрибуты тегового DSL — с однострочным описанием и указанием, где они разобраны
подробнее.

У тегов `<compute>` свои атрибуты (`v`, `sep`, `as`, `width`, `fill`, `from`, `to`,
`size`, `pattern`, `default`). Каждый принадлежит одному тегу и объясняется там, где
разобран этот тег, — см. [справочник compute](compute.mdx).

## Окружение и конфигурация

| Атрибут         | Что задаёт                                         | См.                                                              |
| :-------------- | :------------------------------------------------- | :--------------------------------------------------------------- |
| `version` / `v` | Версия DSL, которую требует файл                   | [Конфигурация](../core-concepts/configuration.mdx)               |
| `count`         | Количество карточек                                | [Детерминизм](../core-concepts/determinism.mdx)                  |
| `seed`          | Сид генератора случайных чисел (воспроизводимость) | [Детерминизм](../core-concepts/determinism.mdx)                  |
| `local`         | Локаль для шаблонных данных                        | [Шаблоны](../generators/template.mdx)                            |
| `inject`        | Свой маркер интерполяции                           | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |
| `mode`          | `memory` / `disk` — семейство движков; `stream` — легаси-псевдоним, форсирующий движок 2 | [Большие объёмы](../guides/large-outputs.mdx)                    |
| `engine`        | `1` / `2` / `3` — форсировать движок (продвинутое) | [Большие объёмы](../guides/large-outputs.mdx)                    |
| `comment`       | Произвольный комментарий                           | [Конфигурация](../core-concepts/configuration.mdx)               |

## Последовательности и зависимости

| Атрибут     | Что задаёт                                                                                                                                                                        | См.                                                                   |
| :---------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------- |
| `name`      | На `<sequence>` — её имя. На `<gen>` — делает его полем, `Имя.Поле`. На `<data>` внутри последовательности — константное поле, единственное, которое не стоит ни одного розыгрыша | [Последовательности](../core-concepts/sequences.mdx#константное-поле) |
| `parent`    | Фильтр по родителю `Родитель.Значение`                                                                                                                                            | [Иерархические зависимости](../guides/hierarchical-dependencies.mdx)  |
| `uniq`      | Уникальная комбинация по всем строкам                                                                                                                                             | [Уникальные значения](../constructs/unique-values.mdx)                |
| `on` / `is` | Субъект / ключ ветки для `<switch>`                                                                                                                                               | [Switch](../constructs/switch.mdx)                                    |
| `filter`    | На `<gen type="pool">`: из каких членов может выбирать эта строка                                                                                                                 | [Согласованные записи](../pools/filter.mdx)                           |
| `of`        | На `<gen type="running">`: какую колонку накапливать. На `<gen type="stat">`: по какой колонке считать                                                                            | [Нарастающий итог](../generators/running.mdx), [Статистика](../generators/stat.mdx) |
| `op`        | На `<gen type="stat">`: какая статистика — `sum`, `mean`, `median`, `min`, `max`, `count` или `stddev`                                                                            | [Статистика](../generators/stat.mdx)                                  |
| `reset`     | На `<gen type="running">`: колонка, смена значения которой перезапускает итог                                                                                                     | [Нарастающий итог](../generators/running.mdx)                         |

## Статистическая форма

| Атрибут          | Что задаёт                                      | См.                                                      |
| :--------------- | :---------------------------------------------- | :------------------------------------------------------- |
| `distribution`   | Именованное распределение (`normal`, `zipf`, …) | [Распределения](../guides/statistical-distributions.mdx) |
| `min` / `max`    | Обрезать выпавшие значения диапазоном           | [Распределения](../guides/statistical-distributions.mdx) |
| `missing`        | Доля строк, оставленных пустыми                 | [Пропуски](../guides/missing-data.mdx)                   |
| `missing_as`     | Чем записывается пустая ячейка                  | [Пропуски](../guides/missing-data.mdx)                   |
| `anomaly`        | Доля строк, сделанных выбросами                 | [Аномалии](../guides/anomalies.mdx)                      |
| `anomaly_factor` | Насколько далеко отодвинут выброс               | [Аномалии](../guides/anomalies.mdx)                      |
| `anomaly_flag`   | Колонка-ответ, помечающая выбросы               | [Аномалии](../guides/anomalies.mdx)                      |

**У каждого распределения свои параметры**, и читаются они только тогда, когда
`distribution=` называет именно его. Кроме них любое распределение принимает
`decimals`, `min` и `max`. Каждый разобран, с гистограммой, в
[руководстве по распределениям](../guides/statistical-distributions.mdx).

| `distribution=` | Параметры         | Что они значат                                                                   |
| :-------------- | :---------------- | :------------------------------------------------------------------------------- |
| `normal`        | `mean` `sd`       | Центр и разброс                                                                  |
| `lognormal`     | `meanlog` `sdlog` | Центр и разброс **логарифма** — само значение скошено вправо                     |
| `exponential`   | `rate`            | Событий за единицу времени; среднее равно `1/rate`                               |
| `pareto`        | `alpha` `xmin`    | Толщина хвоста и наименьшее возможное значение                                   |
| `weibull`       | `shape` `scale`   | `shape` меньше 1 — ранние отказы, больше 1 — износ; `scale` задаёт типичный срок |
| `poisson`       | `lambda`          | Среднее число событий за интервал (потолок 700)                                  |
| `zipf`          | `n` `s`           | Сколько рангов и насколько круто они падают                                      |
| `gamma`         | `shape` `scale`   | Суммарное ожидание `shape` событий, каждое в среднем по `scale`                  |
| `beta`          | `alpha` `beta`    | Тяга к 1 и к 0 — результат лежит между 0 и 1                                     |

## Pattern (рисунок как источник)

| Атрибут           | Что задаёт                                        | См.                                  |
| :---------------- | :------------------------------------------------ | :----------------------------------- |
| `points`          | Пары `x,y` прямо в конфиге вместо файла           | [Pattern](../generators/pattern.mdx) |
| `upper` / `lower` | Две границы — коридор                             | [Pattern](../generators/pattern.mdx) |
| `mode`            | `signal` (траектория) / `density` (распределение) | [Pattern](../generators/pattern.mdx) |
| `y_range`         | `min..max` — вертикальный масштаб                 | [Pattern](../generators/pattern.mdx) |
| `interp`          | `linear` / `smooth` / `step` между точками        | [Pattern](../generators/pattern.mdx) |
| `spread`          | Превратить линию в туннель шириной ±N             | [Pattern](../generators/pattern.mdx) |
| `ink_threshold`   | Насколько тёмный пиксель PNG считать краской      | [Pattern](../generators/pattern.mdx) |

`mode` — это два разных атрибута с одним именем: на `<env>` он выбирает семейство
движков, на генераторе `pattern` — вопрос, который вы задаёте рисунку.
