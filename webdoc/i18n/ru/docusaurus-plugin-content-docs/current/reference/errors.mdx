# Коды ошибок

Все диагностики, которые может выдать TDC, по кодам. Загляните сюда, когда запуск
остановился, а одного сообщения не хватило.

## Как читать диагностику

В диагностике четыре части, и код — та из них, что не меняется между версиями:
формулировку могут улучшить, `TDC193` останется `TDC193`.

<Terminal title="./run demo.tdc">
{`error[TDC193]: "Naem" is not a declared sequence — it would be printed literally
 --> demo.tdc:8:11
  |
8 |     <line><data>\${{Naem}}</data></line>
  |           ^^^^^^^^^^^^^^^^^^^^^^
  |
help: did you mean "Name"?
note: Declare it in <env>, or set a different inject= pattern if you really want the text \${{…}} in the output.`}
</Terminal>

- **код** — что пошло не так; не меняется от версии к версии;
- **место** — файл, строка и колонка, с подчёркнутым виновником;
- **`help:`** — догадка, что вы имели в виду, когда имя похоже на существующее;
- **`note:`** — что с этим делать.

Проверка идёт до генерации, поэтому конфиг с ошибкой не даёт данных вообще, а не
половину файла. Почти каждая диагностика здесь — **ошибка**, и она останавливает прогон:
если конфиг попросил то, чего не получит, TDC отказывается, а не отдаёт данные, которые
выглядят правильно, но таковыми не являются. Исключения — девять **предупреждений**, при
которых прогон завершается: `TDC136` (кривая строка `<map>` пропускается, а корректные
продолжают действовать), `TDC171` (файл пакета, шапка которого не даёт ему никакого
адреса), `TDC200` (оценка памяти большая, но всё же помещается), `TDC216` (выражение,
которое всегда истинно или всегда ложно), `TDC221` (группа `<uniq>` или `<distinct>` с
одним участником, которая ничего не ограничивает), `TDC231` (пул, который никто не
читает), `TDC234` (пул больше 100 000 членов), `TDC236` (колонка `uniq` за
100 000 строк — такая не стримится; во втором своём значении, пул объявлен не в том
порядке, это ошибка) и `TDC251` (доля `percent`, просящая меньше одной строки).
Каждое говорит об этом в своей строке ниже.

Номера раздаются примерно в том порядке, в каком конфиг проверяется — сперва структура,
потом генераторы, потом всё, что построено сверху, — но номер это идентификатор, а не
классификация. Ориентируйтесь на разделы ниже.

## Структура документа

| Код      | Когда срабатывает                                      | Что делать                                                                                                                                  |
| :------- | :----------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------ |
| `TDC001` | В файле нет корневого `<tdc>` **или** файл вообще не разобрался — синтаксическая ошибка, в том числе закрывающий тег с чужим именем (`<sequence>…</gen>`) или вложенность глубже **64 уровней**, до которой не доходит ни одна живая конфигурация, а сгенерированная доходит | Оберните всё в один `<tdc>…</tdc>` либо исправьте синтаксис, на который указывает сообщение. Пока файл не разбирается, остальное не проверяется |
| `TDC002` | У `<tdc>` нет дочернего `<block>`                      | Добавьте `<block>` с раскладкой одной карточки                                                                                              |
| `TDC003` | На `<tdc>` заданы и `version`, и `v`                   | Оставьте одно — это синонимы                                                                                                                |
| `TDC004` | Объявленная версия документа не похожа на версию       | Укажите версию, которую поддерживает рантайм, например `v="0.1"` (значение новее рантайма даёт `TDC005`)                                    |
| `TDC005` | Файл требует версию новее этой сборки                  | Обновите TDC или понизьте объявленную версию                                                                                                |
| `TDC010` | Прямо под `<tdc>` стоит тег, кроме `<env>` и `<block>` | Перенесите его внутрь одного из двух                                                                                                        |
| `TDC013` | Тег вложен туда, где он не разрешён                    | См. [Теги](tags.mdx) — что во что можно класть                                                                                              |
| `TDC014` | Тег, которому нужны дети, записан самозакрывающимся    | Пишите `<env …></env>`, а не `<env …/>` — дети молча пропали бы                                                                             |
| `TDC015` | У тега атрибут, который движок не читает               | Прогон останавливается: конфиг просил то, чего не получил бы. Проверьте написание — в сообщении есть подсказка с ближайшим настоящим именем |
| `TDC020` | `count` не целое неотрицательное                       | `count="1000"`                                                                                                                              |
| `TDC021` | В шаблоне `inject` нет места под `%`                   | Маркеру нужен `%` под имя, например `inject="[[%]]"`                                                                                        |

## Последовательности

| Код      | Когда срабатывает                                                                                                                                                        | Что делать                                                              |
| :------- | :----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------- |
| `TDC030` | У тега, которому нужно имя, его нет                                                                                                                                      | Добавьте `name="…"`                                                     |
| `TDC031` | Имя последовательности начинается с `_`                                                                                                                                  | Этот префикс отдан [встроенным](builtins.mdx)                           |
| `TDC032` | Две последовательности с одним именем                                                                                                                                    | Переименуйте одну — ссылка была бы неоднозначной                        |
| `TDC033` | Имя совпало со встроенным                                                                                                                                                | Возьмите другое: встроенное всегда выигрывает                           |
| `TDC034` | Значение `parent` не в форме `Родитель.Значение`                                                                                                                         | Пишите обе части, например `parent="Gender.Male"`                       |
| `TDC035` | Родительская последовательность объявлена **после** этой                                                                                                                 | Поднимите родителя выше — разбор идёт сверху вниз                       |
| `TDC214` | `parent=` называет составную последовательность                                                                                                                          | Родитель отбирается по значению, а группа полей своего значения не даёт |
| `TDC036` | Внутри `<sequence>` нет `<gen>`                                                                                                                                          | Без генератора последовательность ничего не производит                  |
| `TDC110` | _выведен из обращения_ — безымянный `<gen>` рядом с именованным теперь [собирает значение](../core-concepts/sequences.mdx#составная-по-значению), а не считается ошибкой | —                                                                       |
| `TDC111` | Два поля одной составной последовательности с одним именем                                                                                                               | Переименуйте одно                                                       |
| `TDC129` | `<sequence>` внутри тега уровня конфига не даёт там ничего пригодного                                                                                                    | См. [Последовательности](../core-concepts/sequences.mdx)                |

## Генераторы

| Код      | Когда срабатывает                                                                                 | Что делать                                                                                                                                                                          |
| :------- | :------------------------------------------------------------------------------------------------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TDC040` | У `<gen>` нет `type`                                                                              | Добавьте `type="…"` — см. [Генераторы](generators.mdx)                                                                                                                              |
| `TDC041` | Тип неизвестен или не поддержан для встроенного `<gen>`                                           | Проверьте написание — TDC подскажет ближайшее имя                                                                                                                                   |
| `TDC050` | `type="text"` без `value`                                                                         | Задайте список, например `value="a,b,c"`                                                                                                                                            |
| `TDC051` | В `percent` больше значений, чем в списке `value`                                                 | По одному проценту на значение                                                                                                                                                      |
| `TDC052` | Элемент `percent` — не неотрицательное число                                                      | Заполненные позиции — числа; пустая делит остаток поровну                                                                                                                           |
| `TDC053` | Значения `percent` не дают в сумме 100                                                            | Приведите к сумме 100 или оставьте позицию пустой под остаток                                                                                                                       |
| `TDC060` | `type="file"` без `src`                                                                           | Укажите файл в `src`                                                                                                                                                                |
| `TDC061` | Файл не читается                                                                                  | Проверьте путь — он отсчитывается от конфига, либо используйте `--data-path`                                                                                                        |
| `TDC062` | `column` не разрешается                                                                           | Имя из заголовка (`column="email"`) или номер с единицы (`column="2"`)                                                                                                              |
| `TDC064` | `row` без `column`                                                                                | Связке строк нужно знать, из какой колонки CSV тянуть                                                                                                                               |
| `TDC065` | `type="http"` без `src`                                                                           | Укажите адрес сервиса — `src="http://127.0.0.1:5566/gen"`                                                                                                                           |
| `TDC066` | `src` — не http(s)-адрес                                                                          | Пишите `http://…` или `https://…`, с хостом и путём                                                                                                                                 |
| `TDC067` | `in=` называет то, что не объявлено выше                                                          | Значение на строку берётся из более ранней `<sequence>`                                                                                                                             |
| `TDC068` | `on_error` не `fail` и не `empty`                                                                 | `fail` (по умолчанию) роняет прогон; `empty` оставляет ячейку пустой                                                                                                                |
| `TDC069` | `timeout` — не положительное число секунд                                                          | `timeout="30"` ждёт ответа тридцать секунд; без него — 30 по умолчанию                                                                                                               |
| `TDC070` | `type="template"` без `value`                                                                     | Задайте адрес через точку, например `value="person.lastName"`                                                                                                                       |
| `TDC071` | Адрес шаблона неизвестен                                                                          | Проверьте написание или поставьте пакет, который его даёт                                                                                                                           |
| `TDC072` | `value="date.range"` без `range`, **или** параметр `type="template"`, которого пакет не объявляет | Добавьте `range="…"`; либо проверьте имя параметра — сообщение перечисляет допустимые                                                                                               |
| `TDC073` | Устаревший `range` — не две корректные даты                                                       | Формат `YYYY.MM.DD - YYYY.MM.DD`                                                                                                                                                    |
| `TDC081` | Числовой диапазон записан неверно                                                                 | `value="10..99"`                                                                                                                                                                    |
| `TDC082` | `first_zero` не `true` и не `false`                                                               | Других значений нет                                                                                                                                                                 |
| `TDC083` | `length` не число, не диапазон и не список через запятую                                          | Например `length="8"`, `length="6..9"`, `length="4,6,8"`                                                                                                                            |
| `TDC084` | В `percent` на числовом `value` больше значений, чем допускает диапазон                           | По одному проценту на значение                                                                                                                                                      |
| `TDC085` | Элемент `percent` на числе — не неотрицательное число                                             | Заполненные позиции — числа                                                                                                                                                         |
| `TDC086` | `percent` на числе не даёт в сумме 100                                                            | Приведите значения к сумме 100                                                                                                                                                      |
| `TDC087` | `include`/`exclude` без числового диапазона в `value`                                             | Они фильтруют диапазон, значит он должен быть                                                                                                                                       |
| `TDC088` | `distribution` вместе с несовместимым атрибутом                                                   | Именованное распределение само задаёт розыгрыш                                                                                                                                      |
| `TDC089` | Параметры распределения неверны                                                                   | См. [Распределения](../guides/statistical-distributions.mdx)                                                                                                                        |
| `TDC090` | Атрибут, который обязан быть числом, им не является                                               | Проверьте значение                                                                                                                                                                  |
| `TDC095` | `type="regex"` без `value`                                                                        | Шаблон кладётся в `value`                                                                                                                                                           |
| `TDC096` | `regex_max_length` не положительное целое                                                         | Например `regex_max_length="64"`                                                                                                                                                    |
| `TDC097` | Регулярка не разбирается                                                                          | Почините шаблон — дальше идёт сообщение самого парсера                                                                                                                              |
| `TDC098` | У `type="symbol"` заданы и `value`, и `alphabet`, либо **ни один**                                | Задайте ровно один — набор в `value` или именованный `alphabet`                                                                                                                     |
| `TDC099` | Именованный алфавит неизвестен                                                                    | См. [Символы](../generators/symbol.mdx)                                                                                                                                             |
| `TDC128` | `type="advanced_regex"` без `value`                                                               | Шаблон кладётся в `value`                                                                                                                                                           |
| `TDC128` | _(второе значение)_ `default=` или `if=` написаны на `<case>`                                     | `<mix>` выбирает случай по проценту, `<switch>` — по ключу `is`; условий не спрашивает ни тот, ни другой. Для значений по условию используйте `<sequence>` с ветками `<gen if="…">` |
| `TDC130` | Продвинутый шаблон не разбирается                                                                 | См. [Advanced regex](../generators/advanced-regex.mdx)                                                                                                                              |

## Выражения в `if`

| Код      | Когда срабатывает                                                                                                  | Что делать                                                                                                                                                                                            |
| :------- | :----------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TDC100` | Выражение не разбирается                                                                                           | См. [Вывод и форматирование](../core-concepts/output-formatting.mdx)                                                                                                                                  |
| `TDC101` | Бинарный оператор не поддержан                                                                                     | Поддержаны: `== != === !== < > <= >= && \|\| + - * /`                                                                                                                                                 |
| `TDC102` | Унарный оператор не поддержан                                                                                      | Поддержаны: `!`, `-`, `+`                                                                                                                                                                             |
| `TDC103` | Использован вычисляемый доступ к полю                                                                              | Разрешены только простые имена                                                                                                                                                                        |
| `TDC215` | Имя в `if=`, которого нет ни у одной последовательности                                                            | Оно читается как свой же текст: в одиночку ветка срабатывает всегда, в сравнении — никогда                                                                                                            |
| `TDC216` | _(предупреждение)_ `if="Seq.Value"` называет значение, которого последовательность не выдаёт                       | Ветка мёртвая. Именно предупреждение: сузить список намеренно — нормальная практика                                                                                                                   |
| `TDC217` | Путь шаблона существует, но не для локали прогона                                                                  | Сообщение называет локаль; поставьте `local=` на `<gen>` или `<env>`, либо выберите путь, который есть в вашей локали                                                                                 |
| `TDC218` | `uniq="true"` на последовательности без своих значений — `<compute>` читает другие, `if=` выбирает ветку на строку | Поставьте `uniq=` на те последовательности, которые она читает, либо оберните их в `<uniq>`                                                                                                           |
| `TDC219` | `<compute>` и `<gen>` в одной `<sequence>` — один из двух был бы выброшен                                          | Вынесите `<compute>` в свою `<sequence>` и читайте разыгранную через `<field>`                                                                                                                        |
| `TDC220` | `uniq="true"` на составном значении, склеивающем две и более разыгранные части                                     | У частей нет фиксированной ширины, поэтому уникальный набор частей не даёт уникальную строку: `9`+`15` и `91`+`5` — одни и те же три символа. Оставьте одну разыгранную часть или зафиксируйте ширины |
| `TDC221` | _(предупреждение)_ `<uniq>` или `<distinct>` вокруг менее чем двух `<sequence>`                                    | Группа ограничивает участников друг относительно друга, поэтому один участник не ограничивает ничего. Добавьте второго или напишите `uniq="true"` на самой последовательности                         |

## `<pool>`

См. [Согласованные записи](../pools/overview.mdx).

| Код      | Когда срабатывает                                                             | Как исправить                                                                                                                                                                                                                     |
| :------- | :---------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TDC222` | У `<pool>` нет `name` или нет `count`                                         | Пул читается по имени и держит фиксированное число членов: `<pool name="Doctors" count="30">`                                                                                                                                     |
| `TDC223` | `<pool count="…">` — не целое число не меньше 1                               | Из пула, в котором ничего нет, нечего выдавать                                                                                                                                                                                    |
| `TDC224` | `<gen type="pool" value="X">`, а пула `<pool name="X">` нет                   | В сообщении перечислены объявленные пулы. Объявите его в том же `<env>`                                                                                                                                                           |
| `TDC225` | `filter="field == X"`, где обе стороны не могут совпасть ни на одном значении | Оба списка написаны в конфиге, и они не пересекаются — значит каждая строка сужается до пустоты. Сообщение называет оба. Здесь докладывается только заведомое противоречие; редкое значение отвергается на той строке, где выпало |
| `TDC226` | `filter=` читает `Pool.field`, а такого поля у пула нет                       | В сообщении перечислены поля пула. **Неуточнённое** незнакомое имя не трогают — язык выражений читает голое слово как литерал                                                                                                     |
| `TDC229` | `${{Ref}}`, где `Ref` разыгрывает целого члена                                | Член — это запись, а не значение. Читайте поле: `${{Ref.lastName}}`                                                                                                                                                               |
| `TDC230` | `<block>`, тег обрамления или ещё один `<pool>` внутри `<pool>`               | Пул — это таблица, которую читают другие столбцы, а не то, что пишется в файл; и пулы не вкладываются                                                                                                                             |
| `TDC231` | _(предупреждение)_ `<pool>`, который не читает ни один `<gen type="pool">`    | Он строится целиком до первой строки и держится в памяти весь прогон, так что непрочитанный оплачен и выброшен. Прочитайте его или уберите                                                                                        |
| `TDC232` | Имя в `filter=` является и полем пула, и последовательностью                  | Переименуйте одно из них. Уточнение одной стороны не помогает — второе имя всё равно читается как поле члена, и сравнение выйдет с самим собой                                                                                    |
| `TDC234` | _(предупреждение)_ Больше 100 000 членов                                      | Пул держится в памяти весь прогон — около 320 байт на члена с четырьмя полями. Если имелось в виду число СТРОК, это `count` у `<env>`                                                                                             |
| `TDC235` | Больше 1 000 000 членов                                                       | Причина та же, но уже за гранью разумного прогона. Уменьшите пул или перенесите число в `<env count="…">`                                                                                                                         |
| `TDC236` | _(предупреждение)_ `uniq="true"` более чем на 100 000 строк              | Выбор без возврата означает, что нужно помнить выбранное, поэтому вся колонка остаётся в памяти и прогон не может стримить. Измерено: около 250 байт на значение — 2 000 000 строк стоят примерно 477 МБ. Работает; просто стоит делать это осознанно                                                        |
| `TDC236` | Пул читает пул, объявленный ниже, или сам себя                                | Пулы строятся в порядке объявления, поэтому пул может читать только те пулы, что выше. Поднимите тот, который он читает. Из-за этого же порядка цикл между пулами записать нельзя                                                 |
| `TDC241` | Два пула объявлены под одним именем                                           | Пул берут по имени, поэтому двум одно имя не подходит. Раньше второй молча заменял первый, и единственным следом был `TDC193` в блоке про поле, которого «нет»                                                                    |
| `TDC242` | `anomaly` или `missing` — не число в `[0, 1]`                                 | Оба задают ДОЛЮ значений: `anomaly="0.05"`, `missing="0.1"`                                                                                                                                                                       |
| `TDC243` | `anomaly` на списке `value`, где нет ни одного числа                          | Аномалия умножает число, поэтому список слов вернётся неизменным                                                                                                                                                                  |
| `TDC246` | `anomaly_flag` на `<gen>` внутри `<case>`                                     | Тело ветки — это склейка частей, поэтому флаг на одной части не описывает строку: ставьте `flag="ИМЯ"` на сам `<mix>`                                                                                                             |
| `TDC247` | `step` у `<gen type="date">` не является шагом, которым можно идти, либо смешивает календарную единицу с фиксированной | Пишите `15m`, `1h30m`, `2d`, `3mo`, `1y` — единицы `s`, `m`, `h`, `d`, `w`, `mo`, `y`; голое число означает дни                                                                                                                            |
| `TDC248` | `step` без `order="sequential"` на том же `<gen>`                             | Диапазон никто не обходит — даты по-прежнему берутся случайно. Добавьте `order="sequential"` или уберите `step`                                                                    |
| `TDC249` | `weekdays` называет несуществующий день недели                                 | sun, mon, tue, wed, thu, fri, sat — диапазон `mon..fri` или перечисление `sun,wed`                                                                                                   |
| `TDC250` | `weekdays` при шаге в целое число недель или при календарном шаге              | Две причины под одним кодом. Целое число недель фиксирует день недели, поэтому фильтр совпал бы со всеми строками или ни с одной. Календарный шаг делает обратное — `1mo` идёт четверг, воскресенье, воскресенье, среда, — поэтому какие строки уцелеют, решал бы календарь, а не конфиг |
| `TDC252` | `peak_at` у `<gen type="timeseries">` не число                                 | `peak_at` — это строка, на которой пикует сезонная волна, и считается она как `period`: `peak_at="182"` при `period="365"` ставит пик на первое июля |
| `TDC253` | `peak_at` без `period` на том же `<gen>`                                       | У волны сначала должна быть длина, и только потом — высшая точка. Добавьте `period` или уберите `peak_at` |
| `TDC251` | _(предупреждение)_ Доля `percent` просит меньше одной целой строки            | `percent` — это точная квота по строкам, которые до неё доходят, поэтому 10 % от подмножества в пять строк просят половину записи. Половину записи выдать нельзя: ветка сработает один раз или ни разу, и решает это seed. Поднимите долю или `count` |
| `TDC254` | `repeat=` и `order="sequential"` на одном `<gen>`                             | Оставьте что-то одно. Идущая по источнику колонка берёт по значению на строку, повторяющаяся — несколько разыгранных значений. Вместе движки расходились, поэтому комбинация отклоняется, а не отвечается тремя способами |
| `TDC255` | `decimals=` вместе с `include=` или `exclude=`                                | Уберите одно. Набор, собранный через `include`/`exclude`, состоит из целых, и выбор равномерен по ним — округлять нечего, движок молча выдавал целые |
| `TDC256` | Маска без шаблона — `<mask>` без `pattern=` или `${{X\|mask}}` без аргумента     | Задайте шаблон. Без него маска не оставляет ничего и возвращает пустую строку — колонка выходит пустой |
| `TDC257` | Выражение `if=` вызывает функцию, которой нет | Либо опечатка — тогда рядом стоит близкое имя, — либо одна из `sin`, `cos`, `exp`, `log` и им подобных: у них ответ с причиной, потому что каждый язык считает их чуть по-разному, а сравнение превращает последний бит в другую строку. Сегодня есть: `abs`, `ceil`, `floor`, `max`, `min`, `round`, `trunc` |
| `TDC258` | Функции в выражении `if=` дали не столько аргументов | `abs`, `ceil`, `floor`, `round` и `trunc` берут ровно один; `min` и `max` — сколько дадите |
| `TDC259` | Список `[…]` стоит не справа от `in` | Список — это набор значений для проверки, поэтому он что-то значит только в виде `Country in [US, CA, MX]`. Сам по себе он не даёт условию никакого значения |
| `TDC260` | В `at()` передан не список | Список из `repeat` приходит в выражение склеенным текстом, поэтому `at(Items, 1)` просит второй элемент списка из одного и отвечает пустотой. Сначала разрежьте: `at(split(Items, ","), 1)` |
| `TDC261` | В `at()` передан индекс, который индексом не является | Индекс — целое число, ноль или больше. За концом списка пусто намеренно: строки из `repeat="1..4"` разной длины. А `-1`, `1.5` и `"one"` — ошибки, и каждая из них раньше давала ту же пустую колонку |
| `TDC262` | `<gen type="stat">` не говорит, что считать (`of=`) или какую статистику (`op=`), либо называет несуществующую | Статистика читает чужую колонку и ничего не тянет сама, поэтому нужны оба. `op=` — одно из `sum`, `mean`, `median`, `min`, `max`, `count`, `stddev`; `decimals=` — от 0 до 10 |
| `TDC263` | `${{Name}}` в атрибуте, который его не раскрывает | Интерполяция доходит до текста внутри `<data>` и до `<gen type="template" value=>`, и больше никуда — везде ещё скобки остаются буквальными символами. Чтобы одна колонка зависела от другой, прочтите её в условии `if=` или соберите значение в `<compute>` |
| `TDC264` | `<gen type="date" of="…">` записан неверно | Смещению нужен `plus=` (`7d`, `3..10d`, `1..3mo`, `-10..-3d`), меньшая граница пишется первой, единицы те же, что у `step=`. Атрибуты, задающие СОБСТВЕННЫЙ жребий генератора — `value`, `from`, `to`, `range`, `oldest`, `youngest`, `order`, `step` — ничего не значат, когда `of=` уже поставил дату относительно другой колонки, поэтому они отвергаются, а не игнорируются |
| `TDC265` | У `<assert>` нет условия | Утверждение — единственная конструкция, вся ценность которой в том, что оно ПАДАЕТ, а без `that=` оно не может упасть никогда. Опишите свойство, которым запуск обязан обладать, на языке `if=`, над колонками, одинаковыми для всего запуска |
| `TDC266` | У `<assert>` нет сообщения | `says=` — это то, что читатель увидит месяцы спустя в CI-логе. Одно выражение оставляет ему самому догадываться, что оно защищало |
| `TDC267` | `uniq="true"` вместе с `mask=`, `case=`, `missing=`, `repeat=`, `separator=` или `anomaly=` | Выбор без возвращения строит колонку напрямую и не доходит до слоя, который переписывает значения, — атрибут мог только пропасть. Применить его значило бы сломать другое обещание: маска сводит два разных значения к одним и тем же символам |
| `TDC268` | `if=` на `<gen type="pool">` | Ссылка публикует целую ЗАПИСЬ, а `<gen>` с `if=` становится условной веткой, которую резолвер пула не узнаёт, — ни одна колонка `Ref.field` не регистрировалась, и `${{Ref.name}}` попадал в вывод собственным текстом. Чтобы оставить строки без записи, используйте `parent=` |
| `TDC269` | `if=` на `<gen>` внутри `<case>` | Тело ветки — это несколько частей, склеенных в одно значение, поэтому у условия на одной части нет значения, к которому откатиться. Раньше атрибут принимался и игнорировался, и часть появлялась на каждой строке — включая те, которые условие исключало. Ставьте условие на ветку: `<case if="…">` |
| `TDC270` | В `<tdc>` второй `<env>` или `<block>` | Оба читаются как ПЕРВЫЙ в своём роде, поэтому второй выбрасывается целиком — вместе со всеми объявленными в нём последовательностями и строками, — а прогон завершается как ни в чём не бывало. Ошибка ставится на втором |
| `TDC271` | `percent=` рядом с `order="sequential"` | Обход списка по порядку жёстко задаёт, какое значение достанется строке, — распределять доли уже негде. Проценты принимались и выбрасывались: `percent="98,1,1"` на сотне строк давал 34 / 33 / 33 |
| `TDC272` (предупреждение) | `<env local=…>` называет локаль без переводов дат | Локаль — хороший источник ИМЁН, но названий месяцев не содержит, поэтому даты выйдут по-английски. На `<gen type="date" local=…>` это отвергается (TDC153), а здесь до сих пор молчало. Срабатывает только если формат читает локаль: `format="YYYY-MM-DD"` одинаков на всех языках |
| `TDC273` | аргумент фильтра, которым фильтр не может воспользоваться | `slice:5,2` кончается раньше, чем начинается, и опустошает колонку; `slice:abc`, `group:abc`, `group:0`, `compact:1` и `compact:99` оставляют значение нетронутым. `group` и `compact` БЕЗ аргумента сохраняют документированные значения по умолчанию (3, основание 36) |
| `TDC274` | аргумент у фильтра, который его не читает | `trim`, `sql`, `upper`, `lower`, `capitalize` и `title` — целые преобразования; `${{X\|trim:junk}}` молча игнорировал `junk`. Соединяйте цепочкой: `${{X\|trim\|upper}}` |
| `TDC275` | `replace`, которому нечего искать | `${{X\|replace}}` и `${{X\|replace:,to}}` не меняют вообще ничего. Пишите обе части: `${{X\|replace:from,to}}` |
| `TDC276` | зафиксированный параметр пакета не той длины | У идентификатора с контрольной цифрой жёсткая раскладка, поэтому часть другой длины её ломает, а не сдвигает. `usa.finance.aba_routing prefix="12345"` ронял запуск; `tail="678"` писал шестизначное «не число». Сообщается только там, где длину можно ДОКАЗАТЬ по телу самого пакета |
| `TDC277` | `decimals=`, которому нечего округлять | Без `value=` генератор выдаёт строку ЦИФР — идентификатор, — и округлять там нечего. `<gen type="number" length="4" decimals="2"/>` выдавал 4566, 5773, 5192 |
| `TDC278` | `decimals=` рядом с `length=` | У дробного значения нет целой ширины, до которой можно дополнить, поэтому отбрасывался как раз `length=`: `value="1..9" length="3" decimals="2"` выдавал 3.78, 2.89 |
| `TDC279` | `first_zero="false"`, который диапазон не может выполнить | Любое значение из `0..5` — одна цифра, поэтому трёхзначная запись всегда дополняется нулями. Генератор перебрасывал по сто раз на строку и всё равно выдавал запрещённую форму: 005, 002, 003. Сообщается только там, где это ДОКАЗУЕМО по диапазону |
| `TDC280` | две записи одного диапазона дат | `value=`, пара `from`/`to` и `range=` говорят одно и то же, а генератор читает их в этом порядке и останавливается. `value="2020-05-05" from="1990-01-01" to="1990-12-31"` выдавал 1990-05-11 и молча выбрасывал остальное. `value="today"`, `"now"` и `"birth"` — тоже записи диапазона |
| `TDC281` | диапазон дат кончается раньше, чем начинается | Розыгрыш брал минимум и максимум двух концов, поэтому `from="2020-01-01" to="2010-01-01"` выдавал вполне правдоподобные даты из диапазона, которого никто не писал. `plus="10..3d"` отвергается как опечатка, а не меняется местами, с самого начала; здесь та же опечатка |
| `TDC282` | `order="sequential"` только у части участников связки `row=`                                      | Либо поставьте `order="sequential"` всем участникам, либо снимите — в смешанной связке они перестают читать одну строку на запись                                                    |
| `TDC283` | `anomaly_flag` у `<gen>`, который лишь одна из частей своей `<sequence>` | Флаг отмечает, В КАКИХ СТРОКАХ появился выброс, а последовательности, собранной из нескольких частей — второго `<gen>`, литерала `<data>` или `name=`, который делает этот `<gen>` полем, — некуда положить такую колонку. Вынесите `<gen>` в отдельную `<sequence>`: заодно получите и само значение отдельной колонкой. Та же причина, что у `TDC246`, только уровнем выше |
| `TDC284` | `secret=` записан прямо в конфигурацию, либо пуст | Ключ внутри конфигурации едет всюду, куда едет она сама, — в систему контроля версий в том числе. `secret="env:TDC_HTTP_SECRET"` читает его из окружения, `secret="file:~/.tdc/service.key"` — из файла, которого нет в репозитории. Литерал даёт ПРЕДУПРЕЖДЕНИЕ: сервис на 127.0.0.1 на один вечер — вполне живой случай; `secret=""` — ошибка, потому что подпись без ключа подделает кто угодно |
| `TDC244` | `type="pattern"` без `points`, `src` или `upper`                              | Рисунку нужна форма, откуда читать: `points="0,0 1,5 2,3"`, файл в `src` или `upper`/`lower` для полосы                                                                                                                           |

| `TDC189` | У `<compute>` больше одного `<result>`                                                         | Оставьте один `<result>` — ранние были бы отброшены                                                                                                  |

## Во время генерации

Эти возникают уже при генерации, а не при проверке: конфиг корректен, но сочетание
выполнить нельзя.

| Код      | Когда срабатывает                                                                                  | Что делать                                                                            |
| :------- | :------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------ |
| `TDC160` | `row="…"` на встроенном `<gen>`                                                                    | Связка строк требует `<sequence>`                                                     |
| `TDC161` | Взвешенный выбор `advanced_regex` использован встроенно                                            | Точные проценты считаются по всей колонке — перенесите в `<sequence>`                 |
| `TDC162` | У встроенного счётчика `value` или `step` не число                                                 | `value="1" step="2"`                                                                  |
| `TDC170` | Файл пакета данных не загружается                                                                  | Сообщение называет файл — см. [Свой пакет данных](../data-packs/writing-your-own.mdx) |
| `TDC171` | _(предупреждение)_ Файл пакета данных не получает адреса, поэтому пропускается                     | Добавьте `address:` или `locale:` в шапку либо переместите файл в папку локали        |
| `TDC200` | _(предупреждение)_ Оценка потребности в памяти — большая доля ОЗУ этой машины, прогон продолжается | Для очень больших наборов используйте `mode="disk"`, память остаётся плоской          |
| `TDC201` | Оценка потребности в памяти превышает ОЗУ этой машины                                              | Уменьшите `count`, разбейте на пакеты или используйте `mode="disk"`                   |

:::note[До трёх из них из конфига не добраться]
`TDC160`, `TDC161` и `TDC162` описывают встроенный `<gen>` — написанный прямо внутри
`<line>`, а не в `<sequence>`. Такую форму валидация отвергает раньше, кодом `TDC131`
(`a <gen> is not allowed inside <line>`) или `TDC013`, так что настоящий конфиг до них не
доходит. Достать их можно только низкоуровневым экспортом `render(parse(src).tree)`,
который намеренно обходит непроверенное дерево. По той же причине их нет в четырёх
портах: они собирают из конфига модель, куда такой `<gen>` просто некуда положить.
:::

## Форматирование и модификаторы

| Код      | Когда срабатывает                                             | Что делать                                                                |
| :------- | :------------------------------------------------------------ | :------------------------------------------------------------------------ |
| `TDC190` | `case` — неизвестное преобразование                           | `upper`, `lower`, `capitalize`, `title`                                   |
| `TDC191` | `order` не `random` и не `sequential`                         | Других нет                                                                |
| `TDC192` | Фильтр интерполяции неизвестен                                | См. [Маски и регистр](../guides/masks-and-case.mdx)                       |
| `TDC193` | `${{Name}}` или `${{Name.field}}` называет необъявленное      | Оно попало бы в вывод буквально — проверяется вся ссылка, вместе с полем  |
| `TDC194` | У типизированного `<data>` нет `name`                         | Колонкой становится только именованный `<data>`                           |
| `TDC195` | `repeat` не число и не диапазон                               | `repeat="3"` или `repeat="1..5"` (от 0 до 64)                             |
| `TDC196` | `repeat` применён к `<mix>`                                   | Смесь выбирает одну ветку, а не производит список                         |
| `TDC198` | `separator` без `repeat`                                      | Он склеивает повторы, значит они должны быть                              |
| `TDC199` | Индекс в `mask` записан неверно                               | Индексы с нуля, диапазон через `..` — `x[0..3]`, `w[-1]`                  |
| `TDC202` | `flag` задан, но ни один `<case>` не помечен `anomaly="true"` | Колонка была бы сплошь отрицательной — пометьте ветку-выброс              |
| `TDC203` | `flag` на вложенном `<mix>`                                   | Колонку-ответ несёт только именованная смесь уровня `<env>`               |
| `TDC204` | `repeat` на генераторе, который не умеет повторяться          | Тип назван в сообщении                                                    |
| `TDC206` | `each=""` не называет последовательность                      | Назовите список, по которому идти                                         |
| `TDC207` | `each` называет последовательность с одним значением          | Нужен список — добавьте `repeat` источнику                                |
| `TDC209` | Именованный `<data>` внутри строки с `each=`                  | Такая строка даёт несколько строк, и имя колонки становится неоднозначным |
| `TDC211` | `weight` применён к генератору, отличному от `file`           | Веса берутся из колонки CSV                                               |
| `TDC212` | `weight` без `column`                                         | Веса лежат во второй колонке, её надо назвать                             |
| `TDC213` | `weight` вместе с `order`                                     | `order` идёт по строкам подряд, а взвешивание выбирает их по частоте      |
