# Справочник тегов

Каждый тег языка TDC DSL и указание, где он разбирается подробно.

## Структура

| Тег          | Что это                                                                                                                  | См.                                                                        |
| :----------- | :----------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------- |
| `<!--…-->`   | Комментарий                                                                                                              | —                                                                          |
| `<tdc>`      | Корневой элемент                                                                                                         | [Конфигурация](../core-concepts/configuration.mdx)                         |
| `<env>`      | Окружение: параметры, последовательности, фикстуры                                                                       | [Конфигурация](../core-concepts/configuration.mdx)                         |
| `<sequence>` | Объявление именованной последовательности                                                                                | [Последовательности](../core-concepts/sequences.mdx)                       |
| `<gen>`      | Генератор данных                                                                                                         | [Генераторы](../generators/overview.mdx)                                   |
| `<data>`     | Внутри `<sequence>`: литеральный текст, который склеивается в значение последовательности, а с `name` — константное поле | [Последовательности](../core-concepts/sequences.mdx#составная-по-значению) |
| `<compute>`  | Вычисляемое значение                                                                                                     | [Язык вычислений](../compute/overview.mdx)                                 |

## Макет вывода

| Тег                                                      | Что это                                            | См.                                                              |
| :------------------------------------------------------- | :------------------------------------------------- | :--------------------------------------------------------------- |
| `<block>`                                                | Макет одной итоговой карточки                      | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |
| `<line>`                                                 | Строка внутри карточки                             | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |
| `<data>`                                                 | Внутри `<line>`: литеральный текст с интерполяцией | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |
| `<before>` / `<after>`                                   | Текст до / после всей генерации                    | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |
| `<before_block>` / `<after_block>` / `<delimiter_block>` | Текст вокруг / между карточками                    | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |
| `<before_line>` / `<after_line>` / `<delimiter_line>`    | Текст вокруг / между строками                      | [Вывод и форматирование](../core-concepts/output-formatting.mdx) |

## Распределения и выбор

| Тег         | Что это                                               | См.                                                                                                      |
| :---------- | :---------------------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| `<mix>`     | Распределение: значение, разбитое по точным процентам | [Распределения (mix)](../constructs/mix.mdx)                                                             |
| `<switch>`  | Выбор значения по ключу (таблица соответствий)        | [Таблицы соответствий (switch)](../constructs/switch.mdx)                                                |
| `<map>`     | Компактная таблица `КЛЮЧ:ЗНАЧ` внутри `<switch>`      | [Таблицы соответствий (switch)](../constructs/switch.mdx)                                                |
| `<case>`    | Одна ветка внутри `<mix>` или `<switch>`              | [Распределения (mix)](../constructs/mix.mdx) · [Таблицы соответствий (switch)](../constructs/switch.mdx) |
| `<default>` | Ветка «иначе» внутри `<switch>`                       | [Таблицы соответствий (switch)](../constructs/switch.mdx)                                                |

## Проверка запуска

| Тег        | Что это                                                            | См.                                                          |
| :--------- | :------------------------------------------------------------------ | :------------------------------------------------------------ |
| `<assert>` | Свойство, которым обязан обладать готовый запуск, иначе он остановится с сообщением | [Самопроверяющиеся конфиги](../constructs/self-checking.mdx) |

`<data>` стоит в списке дважды, потому что читается двумя способами. Внутри `<line>`
это вывод: литеральный текст, в который подставляются `${{…}}`. Внутри `<sequence>`
это данные: без имени — клей между генераторами
[составной по значению](../core-concepts/sequences.mdx#составная-по-значению), а с
`name` — [константное поле](../core-concepts/sequences.mdx#константное-поле),
единственное поле, которое не стоит ни одного розыгрыша.

Теги вычислений (внутри `<compute>`) собраны в отдельный список в
[справочнике функций вычислений](compute.mdx).
