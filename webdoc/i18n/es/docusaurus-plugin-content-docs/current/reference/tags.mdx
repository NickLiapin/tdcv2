# Referencia de etiquetas

Todas las etiquetas del DSL de TDC, con el lugar donde se explican a fondo.

## Estructura

| Etiqueta     | Qué es                                                                                                                 | Ver                                                                            |
| :----------- | :--------------------------------------------------------------------------------------------------------------------- | :----------------------------------------------------------------------------- |
| `<!--…-->`   | Un comentario                                                                                                          | —                                                                              |
| `<tdc>`      | El elemento raíz                                                                                                       | [Configuración](../core-concepts/configuration.mdx)                            |
| `<env>`      | Entorno: parámetros, secuencias, fixtures                                                                              | [Configuración](../core-concepts/configuration.mdx)                            |
| `<sequence>` | La declaración de una secuencia con nombre                                                                             | [Secuencias](../core-concepts/sequences.mdx)                                   |
| `<gen>`      | Un generador de datos                                                                                                  | [Generadores](../generators/overview.mdx)                                      |
| `<data>`     | Dentro de una `<sequence>`: texto literal que se concatena en el valor de la secuencia; con `name`, un campo constante | [Secuencias](../core-concepts/sequences.mdx#una-secuencia-compuesta-por-valor) |
| `<compute>`  | Un valor calculado                                                                                                     | [Lenguaje de cálculo](../compute/overview.mdx)                                 |

## Unicidad

| Etiqueta     | Qué es                                                 | Ver                                                           |
| :----------- | :----------------------------------------------------- | :------------------------------------------------------------ |
| `<distinct>` | Campos/secuencias que deben diferir dentro de una fila | [Sin repeticiones dentro de una fila](../guides/distinct.mdx) |
| `<uniq>`     | La combinación de secuencias única en todas las filas  | [Valores únicos](../constructs/unique-values.mdx)             |

`<data>` aparece dos veces porque se lee de dos maneras. Dentro de una `<line>` es
salida: texto literal en el que se interpolan los `${{…}}`. Dentro de una
`<sequence>` es dato: sin nombre, es el pegamento entre los generadores de una
[secuencia compuesta por valor](../core-concepts/sequences.mdx#una-secuencia-compuesta-por-valor);
con `name`, es un [campo constante](../core-concepts/sequences.mdx#un-campo-constante),
el único campo que no cuesta ni un sorteo.

Las etiquetas de cálculo (dentro de `<compute>`) tienen su propia lista en la
[referencia de funciones de cálculo](compute.mdx).
