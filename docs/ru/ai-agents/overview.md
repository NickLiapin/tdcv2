# TDC для ИИ-агентов

Конфиги TDC может писать за вас агент для программирования. Вы просите обычными словами —
«500 клиентов из 20 стран в CSV», «тест на pytest для `validate_user` на 50 разных
пользователях», — а агент пишет конфиг `.tdc`, проверяет его движком, генерирует файл на
вашем компьютере и отдаёт вам данные вместе с конфигом, который их воспроизводит.

Для этого агенту нужны две вещи, и проект
[`tdcv2-agents`](https://github.com/NickLiapin/tdcv2-agents) даёт обе:

- **Скилл** (skill) — инструкция, которую агент читает перед работой. Он учит языку TDC,
  порядку работы и ловушкам, которые `check` движка не ловит. Затем агент сам запускает
  движок в своём терминале.
- **MCP-сервер** `tdcv2-mcp` — то же знание в виде инструментов, которые агент вызывает:
  проверить конфиг, сгенерировать, найти и установить пакеты данных, кратко описать файл,
  прочитать эту документацию. MCP (Model Context Protocol) — стандартный способ, которым
  агент вызывает инструменты другой программы.

Обе части выходят вместе, под одной версией: 0.1.5.

## Что выбрать

| Ваш агент                                       | Что установить                          | Страница                                                          |
| :---------------------------------------------- | :-------------------------------------- | :---------------------------------------------------------------- |
| Claude Code                                     | плагин — он ставит обе части            | [Claude Code](./claude-code.md#top)                                  |
| Codex, Cursor, VS Code с Copilot, Gemini CLI    | скилл; при желании добавьте и сервер    | [Другие агенты](./other-agents.md#top)                               |
| любой другой MCP-клиент                         | сервер                                  | [Другие агенты](./other-agents.md#mcp-сервер-в-других-клиентах)  |

Агенту с терминалом достаточно скилла. Сервер подходит клиенту без терминала или агенту,
которому удобнее инструменты, чем инструкции. Обе части сразу ничему не мешают: они учат
одному и тому же.

Для всего нужен Node.js 20 или новее.

## Версии

Выпуск 0.1.5 проверен с TDC 0.3.5. Справочник скилла
собран из документации этой версии движка, и агент запускает именно её:
`npx -y tdcv2@0.3.5`. Сервер берёт `tdcv2` вашего проекта, если он там
установлен, а иначе — движок, который идёт вместе с ним. С другой версией движка агент
читает страницы этой версии, а последнее слово остаётся за `check` движка.

## Приватность

Движок работает на вашем компьютере. Ни скилл, ни сервер никуда не отправляют ваши данные и
конфиги. Сервер читает файлы `.tdc` и пишет сгенерированные файлы только внутри папки, в
которой его запустили.

Сеть нужна только для четырёх вещей:

- при первом запуске `tdcv2-mcp` и движок скачиваются из npm;
- с версией движка, отличной от 0.3.5, агент может прочитать страницу
  документации этой версии с GitHub;
- пакеты данных скачиваются, когда вы или агент запускаете `tdcv2 pack add`; через сервер
  это `tdc_pack_add`, и клиент сначала спрашивает вашего разрешения;
- конфиг с `<gen type="http" src="…">` отправляет указанные значения по этому адресу — и
  только если кто-то напишет такой конфиг.

Полностью правила — в [PRIVACY.md](https://github.com/NickLiapin/tdcv2-agents/blob/main/PRIVACY.md).
