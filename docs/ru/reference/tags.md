# Справочник тегов

Каждый тег языка TDC DSL и указание, где он разбирается подробно.

## Структура

| Тег                 | Что это                                        | См.                                                |
| :------------------ | :--------------------------------------------- | :------------------------------------------------- |
| `<!--…-->`          | Комментарий                                    | —                                                  |
| `<tdc>`             | Корневой элемент                               | [Конфигурация](../core-concepts/configuration.md#top) |
| `<env>`             | Окружение: параметры, последовательности, фикстуры | [Конфигурация](../core-concepts/configuration.md#top) |
| `<sequence>`        | Объявление именованной последовательности      | [Последовательности](../core-concepts/sequences.md#top) |
| `<gen>`             | Генератор данных                               | [Генераторы](../generators/overview.md#top)           |
| `<data>`            | Внутри `<sequence>`: литеральный текст, который склеивается в значение последовательности, а с `name` — константное поле | [Последовательности](../core-concepts/sequences.md#составная-по-значению) |
| `<compute>`         | Вычисляемое значение                           | [Язык вычислений](../compute/overview.md#top)         |

## Макет вывода

| Тег                 | Что это                                        | См.                                                |
| :------------------ | :--------------------------------------------- | :------------------------------------------------- |
| `<block>`           | Макет одной итоговой карточки                   | [Вывод и форматирование](../core-concepts/output-formatting.md#top) |
| `<line>`            | Строка внутри карточки                          | [Вывод и форматирование](../core-concepts/output-formatting.md#top) |
| `<data>`            | Внутри `<line>`: литеральный текст с интерполяцией | [Вывод и форматирование](../core-concepts/output-formatting.md#top) |
| `<before>` / `<after>` | Текст до / после всей генерации              | [Вывод и форматирование](../core-concepts/output-formatting.md#top) |
| `<before_block>` / `<after_block>` / `<delimiter_block>` | Текст вокруг / между карточками | [Вывод и форматирование](../core-concepts/output-formatting.md#top) |
| `<before_line>` / `<after_line>` / `<delimiter_line>` | Текст вокруг / между строками   | [Вывод и форматирование](../core-concepts/output-formatting.md#top) |

## Распределения и выбор

| Тег                 | Что это                                                | См.                                       |
| :------------------ | :----------------------------------------------------- | :---------------------------------------- |
| `<mix>`             | Распределение: значение, разбитое по точным процентам  | [Распределения (mix)](../constructs/mix.md#top)  |
| `<switch>`          | Выбор значения по ключу (таблица соответствий)         | [Таблицы соответствий (switch)](../constructs/switch.md#top) |
| `<map>`             | Компактная таблица `КЛЮЧ:ЗНАЧ` внутри `<switch>`       | [Таблицы соответствий (switch)](../constructs/switch.md#top) |
| `<case>`            | Одна ветка внутри `<mix>` или `<switch>`               | [Распределения (mix)](../constructs/mix.md#top) · [Таблицы соответствий (switch)](../constructs/switch.md#top) |
| `<default>`         | Ветка «иначе» внутри `<switch>`                        | [Таблицы соответствий (switch)](../constructs/switch.md#top) |

## Целые записи

| Тег                 | Что это                                                 | Где почитать                                       |
| :------------------ | :----------------------------------------------------- | :------------------------------------------------- |
| `<pool>`            | Небольшая таблица, построенная до строк; строка берёт из неё одного члена целиком | [Согласованные записи (pool)](../pools/overview.md#top) |

## Уникальность

| Тег                 | Что это                                                | См.                                       |
| :------------------ | :----------------------------------------------------- | :---------------------------------------- |
| `<distinct>`        | Поля/последовательности, не совпадающие в одной строке          | [Без повторов в строке](../guides/distinct.md#top) |
| `<uniq>`            | Комбинация последовательностей, уникальная по всем строкам       | [Уникальные значения](../constructs/unique-values.md#top) |

`<data>` стоит в списке дважды, потому что читается двумя способами. Внутри `<line>`
это вывод: литеральный текст, в который подставляются `${{…}}`. Внутри `<sequence>`
это данные: без имени — клей между генераторами
[составной по значению](../core-concepts/sequences.md#составная-по-значению), а с
`name` — [константное поле](../core-concepts/sequences.md#константное-поле),
единственное поле, которое не стоит ни одного розыгрыша.

Теги вычислений (внутри `<compute>`) собраны в отдельный список в
[справочнике функций вычислений](compute.md#top).
